财务人员新增“财务办理”栏目。首次使用需核对真实合同分期、未付费用、各类剩余成本、资金期初和岗位绩效制度；未配置项会显示待完善，产品不代填比例及凭据。

运行 `npm run check:closed-loop` 可重新生成本地完整主链、审批政策和22项专项结果；微信自动化已启动时可用 `FRANCHISE_WS` 指定其地址，运行 `npm run check:closed-loop:native`。两者证据层级不同。外部服务和正式上线未由本地测试证明，不执行真实付款或发布。
