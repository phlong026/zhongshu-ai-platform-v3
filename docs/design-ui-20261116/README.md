# AI 设计页面与预算流程优化（2026-11-16）

本轮包括最初九张页面截图、补充的预算结果页与发送至客户页，以及新增的设计委托入口。修改为原生小程序代码，不新增网站或另做价格维护页面。

## 页面改动

- 首页：删除标记的副文案和提示，压缩入口高度，补封面懒加载。
- 灵感库：删除重复标题与长说明；风格读取原设计后台分类接口，包括后台新增风格；层数复用原小程序 1～4 层选项。分类可换行，失败可重试。修正已有卡片时仍出现空态及方案数量丢失的问题。
- 平面、立面：删除重复标题、参考案例大卡、标记说明与重复像素尺寸；完整显示图纸类型和风格选项，保留清晰度、方向、数量与计费确认。
- 快速预算：统一卡片、输入框、下拉与按钮；清理配置名称；导入参数和历史作为次级入口。地区、层数选择器定位当前值，从当地单价返回时刷新可选目录。
- 预算结果：标题改为“预算小计”，移除标记的来源文字、精确金额入口和预算说明大卡，补主体和外装图标；底部四个入口为保存预算单、发送至客户、重新测算、预算历史。完整预算仍可导出预算图。
- 发送至客户：更名并删除顶部说明，明确客户选中态与底部操作。
- 设计委托：预算结果新增入口；选择客户后先归档当前预算 revision，再进入已有设计委托表单。仅打开表单，不自动提交委托；失败重试沿用归档幂等键。保留所选客户名称；新委托显示“待发起委托”。

## 真实价格来源

已定位同服务器 `/opt/zhongshu` 的原 AI 设计后台，直接复用现有 `GET /admin-api/design/v1/budget/prices`。

用户已明确批准创建专用只读服务账号。已创建独立账号及 OAuth 客户端，仅具有 `design:budget:query`；凭据只在服务器秘密配置中。原价格接口查询成功，读取 35 条发布记录；改价探测返回 403；OAuth 刷新成功。新适配类已在服务器独立运行并直读真实源接口成功，没有读取本地导入价，没有发起收费测算。

Provider 代码、外部连接配置和 systemd 凭据挂载均已准备。未重启线上服务、未发布后端或上传新的小程序版本；线上生效需部署本轮代码。源价格未修改。
