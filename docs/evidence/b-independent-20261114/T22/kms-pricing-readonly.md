# 腾讯云 CBS 加密与 KMS 费用核实（只读）

核实时间：2026-11-14；未登录新的账号，未打开计费控制台，未开通 KMS、未购买资源、未变更权限。

## 可确认结论

1. **不能据此认定“首次启用 CBS 加密一定要购买 KMS 专业版/独享版”。**
   CBS 官方文档说明，首次使用时系统会在该地域自动创建唯一、专用于云硬盘加密的 CMK；用户不能指定、删除或更改该 CMK。首次操作需要按页面提示授权 KMS 服务角色 `CVM_QcsRole`，否则无法购买加密云硬盘。文档没有说这一步必须购买专业版或独享版。
2. **也不能将 CBS 加密写成“肯定完全免费”。** CBS 说明云硬盘加密本身、盘内读写不额外收费；但创建/挂载/卸载加密盘、创建/回滚快照等管理操作会以 API 使用 KMS，并称 KMS 使用会产生费用。
3. **当前 KMS 公开定价可确认的付费 SKU 是专业版 `7,699 元/月`（含 1,000 CMK、5 DEK）；独享版需联系商务。** 但该定价页没有明确把 CBS 自动 CMK 映射到专业版 SKU，也没有给出“自动 CMK”或 CBS 管理操作的独立单价/调用量。因此不能把 `7,699 元/月` 写入本项目的 CBS 加密预算，也不能以历史免费额度承诺新开通账户免费。
4. **历史“标准版”表中有“云产品密钥免费、API 前 20,000 次免费、其后 1.2 元/万次”的字段，但标准版已于 2023-03-17 停止新购；基础版已于 2025-03-14 停止新购。** 该字段不能作为 2026 年新启用 CBS 加密的报价依据。
5. **现有非加密盘不能原地转换为加密盘，反向也不能。** 官方建议新建加密盘，再用 `rsync`（Linux）或 `robocopy`（Windows）复制数据。系统盘加密仍处于试用阶段且需在线支持申请。

## 对本次 B 独立部署的费用决定

- 现有 B 盘的控制面证据显示 `Encrypt=false`；本轮不启用 CBS 加密，不触发上述授权、迁移或潜在 KMS 计费路径。
- 若后续有合规要求要启用加密，先在腾讯云实际订单/支付确认页取得该账号、上海地域、CBS 加密路径的实时报价与 KMS 版本归属，再批准：服务角色授权、创建新加密盘、数据复制、恢复演练和切换。不能从本文档推导零费用或固定月费。
- 这不是当前 40 GiB 数据盘的空间障碍，而是一个独立的合规/迁移/价格确认事项。
