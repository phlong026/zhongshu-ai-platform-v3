## 资料编辑和删除的使用方式

进入“学习培训 → 资料库”，每行都有“编辑”“删除”，右侧详情也有对应入口。

- **编辑资料**：修改名称和分类，保存后列表和详情同步更新。编辑需要管理员权限，并记录审计事件。
- **替换文件**：在右侧选择“上传新版本”。已发布课程继续使用原先明确引用的版本，课程确认替换并重新发布后更新。
- **删除资料**：确认后将该资料及其全部版本从可用资料中移除，同时使原来的下载票据失效。删除采用逻辑删除，云端历史文件保留用于审计。
- **引用保护**：当前课程草稿或已发布课程引用任一版本时，阻止删除并提示关联课程。处理引用后才能删除；历史已下架的发布快照不会单独阻止删除。
- **并发保护**：编辑、删除都校验资料修订号。上传新版本也会增加修订号，旧窗口中的操作需要刷新；课程保存、发布、资料删除和处理任务领取使用同一租户的短事务锁。
- **处理中资料**：正在转换的资料不能删除；尚未完成的上传可以取消。员工及跨租户请求不能编辑或删除资料。
