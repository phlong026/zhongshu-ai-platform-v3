# 业务、工程、管理主链路与责任人详解

日期：2026-10-23。依据：已完成的六角色验收及交付提交 `0c9ad27`。本文展开实际已实现和已测试的流程，编号对应《六角色全流程验收清单》；每一行说明谁办理、办理什么、形成什么结果，以及下一步由谁接手。

责任人是本轮固定模拟人员。客户、业主、供应商和施工班组是业务参与方，其确认或线下凭据由下表指定的系统经办人登记，不额外虚构系统登录角色。设计行政只登记线下设计完成与成果下发；财务只登记实际收付款。

## 二、业务主链路

主链：**李业务内容获客 → 李业务建档跟进 → 李业务预算与委托 → 张老板费用审批 → 王财务首款付款 → 罗财务核实到账 → 林设计登记完成 → 王财务尾款付款 → 罗财务核实足额到账 → 林设计下发 → 李业务确认/登记修改 → 林设计修改后再下发 → 李业务移交 → 张工程接收。**

## 三、工程主链路

主链：**张工程接收 → 张工程开工准备和合同分期 → 张老板审批 → 王财务开工收款 → 张工程实际开工 → 节点资金/材料/施工记录 → 王财务补齐采购金额 → 张老板审批需审批款项 → 王财务付款 → 张工程确认到货及节点完成 → 王财务登记封顶款 → 张工程交付、归档、保修 → 王财务与张工程回查原单。**

### 3.2 材料、付款和节点施工：E05—E09

本例五个施工节点依次为：**基础工程 → 1层主体 → 2层主体 → 主体封顶 → 后续合同工程**。各节点实际登记人均为张工程，不能以财务付款或普通现场记录代替节点完成。

| 步骤 | 责任人 | 输入与具体操作 | 输出/完成条件 | 下一位接手人 |
| --- | --- | --- | --- | --- |
| E05-1 节点资金计划 | 张工程 | 从本项目、本节点填写预计用款、日期和用途 | 只形成预计计划，不伪造实际付款或重复应付 | 张工程 |
| E05-2 多项材料计划 | 张工程 | 填写材料名称、数量、单位、计划到货等 | 材料与计划、项目、施工节点关联；未知金额保留待完善 | 到货→张工程；金额→王财务 |
| E06-1 先货后款、分批到货 | 张工程 | 按原材料计划登记各批实际到货、数量、日期与凭据 | 同一材料分批累计，不超过计划，不因第一次到货直接算齐 | 王财务补采购金额；张工程查到货差额 |
| E06-2 补采购金额 | 王财务 | 打开原材料对应事项，核对供应商、单价、运费及采购凭据 | 原材料计划生成可回溯的采购金额与应付，不能另立无来源付款 | 需审批时→张老板 |
| E06-3 审批材料付款 | 张老板 | 核对原项目、原材料应付、金额与凭据并办理审批 | 批准仍不等于已经付款 | 王财务 |
| E06-4 实际材料付款 | 王财务 | 从已批准原应付登记实际付款日期、金额、流水与凭据 | 付款回写原材料计划和项目成本；到货事实保持独立 | 张工程回查原计划 |
| E07-1 现场记录 | 张工程 | 在当前节点记录实际工序、说明与现场凭据 | 形成原节点普通现场记录，保留经办人 | 张工程 |
| E07-2 节点完成 | 张工程 | 核对顺序、材料到货和本节点施工资料，登记验收完成 | 满足条件后将原节点完成并保留责任与凭据 | 张工程进入下一节点 |
| E08-1 提出预付材料计划 | 张工程 | 在下一节点提出材料需求，保留原项目和节点关联 | 形成先款后货的原材料计划 | 王财务 |
| E08-2 完善采购金额 | 王财务 | 沿原材料计划填写供应商、单价、运费和采购凭据 | 原材料应付金额明确，进入原付款审批 | 张老板 |
| E08-3 预付审批 | 张老板 | 核对本节点材料用途与原应付，批准付款 | 形成已批准应付，尚未形成实际付款或到货事实 | 王财务 |
| E08-4 实际预付 | 王财务 | 按已批准原应付登记实际付款与凭据 | 先形成付款事实；材料尚未到货时仍保持未到齐 | 张工程 |
| E08-5 预付后收货 | 张工程 | 对同一材料和计划登记实际到货并核对数量 | 付款与到货分别有记录，满足材料条件后才继续节点 | 张工程 |
| E09-1 顺序施工至封顶 | 张工程 | 依次办理各施工节点，不跳过有前置约束的节点 | 主体封顶事实触发第二期收款事项 | 王财务 |
| E09-2 封顶款登记 | 王财务 | 在原合同第二期登记实际到账 40000 元及流水、凭据 | 工程累计实收 100000 元，与原合同总额一致 | 张工程 |
| E09-3 后续合同工程 | 张工程 | 继续办理后续合同节点与资料 | 本例五个节点全部完成；合同与材料仍可回查 | 张工程进入交付准备 |

## 六、流程连通和数据核对要点

| 核对项 | 谁负责源事实 | 上下游如何对应 |
| --- | --- | --- |
| 内容→客户 | 李业务 | 作品、发布、咨询、客户来源关联；同手机号复用原档案 |
| 客户→设计委托 | 李业务 | 同一客户、项目、预算版本、需求和费用，不靠名字相同来拼接 |
| 付款→总部到账 | 王财务→罗财务 | 原项目、原期次、原付款来源、金额与流水逐笔核对；差额累计明确 |
| 设计→移交 | 林设计→李业务→张工程 | 正式下发版本、客户确认、移交版本和工程收到的图纸保持一致 |
| 业务→工程 | 李业务→张工程 | 继承原项目和来源客户；退回补充不重新建工程 |
| 材料→付款→到货→节点 | 张工程→王财务/张老板→张工程 | 原材料计划、供应、到货、应付和付款关联；付款不替代到货，现场记录不替代节点完成 |
| 工程合同→客户实收 | 张工程/张老板→王财务 | 两期约定合计等于合同；分笔实收按期累计，本例三笔共 100000 元 |
| 原业务→管理汇总 | 各原经办人→张老板查看 | 同组织、同周期、同人员归属，统计明细能回原单，不另造事实 |
| 内部交接 | 张老板→接手人 | 变更当前责任、保留历史作者和交接原因，不覆盖历史归属 |
