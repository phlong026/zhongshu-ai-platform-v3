# 用户名自动匹配修复（2026-11-16）

用户输入用户名后自动匹配，无须点击查找。沿用后端至少2个字或字母的查询规则，输入停顿300ms后提交最后一次查询；唯一完整结果自动选中，多个结果由用户选择。结果被截断时不自动选择，保留补充姓名或地区的提示。

移除“查找”按钮，保留键盘搜索用于立即查询或失败后重试。匹配中显示状态；确定账号前不能输入密码。修改输入时立即清空旧选择和密码，旧请求迟到不能覆盖新结果。切换微信、清空默认账号、选择候选、隐藏或关闭页面均取消待执行查询。
