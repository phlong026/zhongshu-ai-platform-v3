# R13 实体费用纯登记

实体设计费、合同款及工程款继续复用现有财务登记、凭证、核算、更正及退款留痕。付款在外部完成，平台不生成这类费用的在线支付单。

## 变更

- CommissionSimulatedPayments.allowed 始终为 false；旧组织演练配置仅兼容启动，不再开启模拟收银。
- create/pay 在任何配置下拒绝，旧接口不能绕过页面禁用。
- 保留原模拟订单的只读收据；不把这些记录回填为实际收支。
- 历史模拟委托若要正式交付，仍必须经过已有逐单审核和真实结算门禁。
- 小程序配对 PR 删除模拟收银、显式测试开关及旧 pay 深链；旧草稿必须重新核对费用后提交，不能自动变成正式费用。
- 公司 AI 额度充值的微信 XPAY 属于 R20，本任务不改变其支付和额度账本。

## 验证

独立代码专项评审通过。新增/调整 SixRoleCommissionIntegrationTest：旧配置无法开启、拒绝新模拟委托及 create/pay、保留授权历史查询、外公司拒绝、没有新增模拟命令与实际收支；保留历史模拟单正式审核后的真实结算和资料门禁测试。

本地 Java17 语法解析及 diff 检查通过；本地没有 Maven/PostgreSQL，真实数据库结果以 Backend CI 为准。迁移不删除历史订单或余额。
