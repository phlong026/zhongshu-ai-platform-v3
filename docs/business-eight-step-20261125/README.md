## 2026-11-25 当批决定

1. 业务员底部保留“首页、创作、客户、我的”，移除“方案/资料”独立标签。
2. 灵感检索作为首页工具。后续在客户第 03 步“户型选择”增加关联参考方案的入口。
3. 公告为独立模块，从“我的 → 公司公告”进入；后台独立发布、撤回及管理，不再采用首页置顶公告模块的旧方案。
4. 公告和个人业务消息独立存储。加盟商可读全品牌公告和本品牌公告；总部管理员与总部财务可读全部品牌，总部财务不能发布。
5. 八步顺序仍为：邀约进店、店面讲解、户型选择、带看工地、现场测量、别墅报价、合同签约、开工大吉。

## 销售导航任务的具体行为

- 业务员和业务负责人的原生导航编号保留为 `1 / 5 / 7 / 4`，不重新编号。
- `pages/engineering/index` 是其他岗位仍使用的原生页面，保留注册。业务员直达旧地址时回业务首页，不再绘制旧方案 tab。
- 业务员的旧 `pages/design/index` 入口转向灵感库；工具页冷启动返回业务首页。
- 首页的灵感入口直接复用现有灵感库。客户参考关联属于八步表单任务，本次不会把“浏览了户型”记成第 03 步完成。
- 两个工具位于“首页 → 常用功能”，在“今日待办”下方、“最近办理”上方；四个入口依次为“登记客户、灵感检索、快速预算、提交委托”。原“方案预算”仅更名为“快速预算”，跳转及计算、扣费行为不变。
- 现有“客户详情 → 跟进 → 业务办理”也保留灵感检索和快速预算入口，并携带当前客户 ID。第 03 步和第 06 步的专属入口及完成校验尚待八步表单任务实现。
