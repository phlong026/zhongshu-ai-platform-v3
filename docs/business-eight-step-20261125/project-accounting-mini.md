# R14 项目核算小程序

配套后端：`project-accounting-contract.md`。本分支基于 R01 总部工作台提交，保持两个代码库分别交付。

## 可达入口

- 财务工作台 → 项目账本 → 项目核算 → 核算与确认记录。
- 老板 / 业主的项目只读账页 → 项目核算与结项确认；进入后保持只读。
- 总部工作台 → 公司账本 → 项目账本，在原账汇总下显示当前核算及最近确认的历史金额。

新增 `/pages/admin/accounting/index?projectId=...`。普通门店页只允许真实门店的财务、财务负责人、老板、业主进入；只有财务两岗且服务端 `canConfirm=true` 才展示确认表单。总部页面复用独立 HQ API 的账本投影，不跳到门店写接口。

## 页面与交互

分开显示已签合同金额、已确认项目费用、客户净收款、公司净付款、现金结余和合同毛利。金额采用分字符串精确格式化，空合同收入 / 毛利显示“—”，不补零或猜数。

确认前要求勾选“费用已完整归集”并填写说明；提交内容只有来源 hash、预期版本和人工确认，不接受客户端计算金额。未知结果冻结原请求与幂等键，提供显式重试；切换身份不复用旧请求。历史确认保留原金额，以分页显示。

页面离开后清除金额和历史；切岗、撤权及迟到响应不恢复旧数据。重新加载当前核算会使旧历史分页失效，并在当前读取期间禁止开启下一页，完成后从第一页重新读。
