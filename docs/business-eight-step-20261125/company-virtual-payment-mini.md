# R20 公司额度充值入口收口

额度卡和旧套餐深链统一进入现有微信虚拟支付公司充值页。packages API 使用真实公司充值目录；旧模拟 purchase 直接拒绝，无网络写入，历史本地模拟订单不重放、不删除。

订单只在后台确认公司额度到账后显示已到账。REFUNDING、REFUNDED、REFUND_REVIEW 分别显示退款处理中、已退款、额度待核对，不提供继续支付。支付前保持现有登录校验、套餐重读、价格版本复核、微信 requestVirtualPayment 与后台查单恢复。

不更改个人历史账、视频任务失败退额或真实付款协议。微信适配器尚未开放自动发起真实退款，不能把前端新增退款展示视为渠道退款已经开通。

专项测试 24/24、完整 npm run check 通过，独立评审通过；随后移除了 check 中重复执行的 profile-services 测试，因为 check:company-points 已包含同一文件。未进行微信真机付款/退款。
