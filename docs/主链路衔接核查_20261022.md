# 业务 → 工程 → 管理 主链路衔接核查（2026-10-22）

## 核查方法
| 范围 | 脚本 | 判定 |
| --- | --- | --- |
| 业务：创作→客资→预算→委托→首/尾款→设计行政→移交→工程接收 | `verify-sales-todo-handoffs`（`npm run check:business:simplified`） | 每一环办理完成后，下一岗位首页出现唯一待办，点开即为办理页；上一环待办关闭 |
| 工程：接收→准备→开工→节点/材料/收款→交付→归档→财务结清 | `walk-main-chain`（`npm run check:chain:walk`） | 逐步回放 23 个办理环节：办理人从**自己首页**点选可见控件，3 步内能打开办理页；每步之后五类岗位首页所有入口可打开、不落到别的页面 |
| 全岗位导航 | `crawl-navigation`（`npm run check:navigation:crawl`） | 逐岗位从首页点遍所有跳转：无权限页、记录不存在、报错、落点与链接不一致 |

## 本轮发现并修复
1. 工程归档后，财务负责人首页没有任何“下一步”——只能自己翻到项目账目才能发现“待确认财务结清”。现在归档后出现“核对项目成本”，核对完转为“确认结清”，结清后待办关闭（`verify-engineering-records` 已加断言）。
2. 工程页“查看业务端图纸/抄送记录”等旧链路视图已被清理，链接静默落到客户列表。现在带客户编号时落到该客户详情；新流程客户仍进入委托进度。
3. 同一笔待核算收款，门店财务同时有“登记到账”和“凭据预查”两条待办，现只保留“登记到账”。
4. 此前已修：工程负责人进入工程工作台报无权限、老板应付/计划/待办行跳到无权页、账目链接指向不存在的项目账目、设计团队入口失效。
