# 加盟商财务运行联调与界面优化验收

日期：2026-11-17。

## 验收范围与环境

本轮覆盖财务首页、月份选择、账本列表、项目/公司账本、费用与员工往来、收付款登记、前期账本关联工程、凭据与明细，以及业务、工程、财务、老板的数据核对。

截图来自微信开发者工具的原生小程序模拟器，属于实际代码运行页面。没有连接物理手机，尚未完成物理手机上的字体、软键盘及系统差异验收。未上线，未操作生产账务，未发生真实银行转账。

后端运行在独立 PostgreSQL/Redis 环境，使用真正的登录会话、岗位权限和 HTTP 接口。截图中的“联调”项目、人员和金额均为测试数据。设计委托的已审来源和工程关联属于预置场景；本轮没有声称覆盖设计委托的完整审批、出图与移交流程。收款申报、核实、采购、付款、垫付、报销、手工补记及账本关联均通过实际业务接口或原生页面操作完成。

## 页面检查与调整

1. **首页和月份选择：已通过。** 保持问候、指标、今日待办、快捷办理、正在办理的顺序。月份在右上角，以 `2026-11` 显示。日历胶囊展开底部月份面板，切换年份后直接选月，确认才刷新，取消保留原月份。切换月份不会隐藏持续待办。
2. **账本列表：已通过。** 公司日常、项目、前期账本支持搜索和筛选。去掉重复空状态、无关的月份筛选和英文工程状态。新建账本后能实际进入详情。
3. **项目及公司账本：已通过。** 上方突出收支结余，收款、付款、待收、待付分开排版。金额加千分位，币种字号次于金额。操作区缩小，三个标签统一为文字加底部指示线，去掉大块选中底色。
4. **收支、费用、员工往来：已通过。** 公司现金流水、费用依据、员工往来分别展示。设计费垫付与员工报销不重复计入项目费用；员工往来按人和原垫付事项汇总，展示垫付、已报销、尚待报销，不再堆叠三种原始记录。
5. **登记和前期账本：已通过。** 原生界面完成新建前期账本、补记收款 1,000 元、补记运输付款 860 元、关联已有工程。关联后两种账本入口读取同一范围，金额没有翻倍。已收定金整笔抵扣合同期次，未新建第二笔现金收款。
6. **明细和凭据：已通过接口及页面检查。** 明细列表不展示 `null`、来源串、雪花编号。编号、账户、对方及凭据放入详情。补充说明能够回读。使用现有账本图标作为测试附件，验证上传、校验、补充和授权下载；该附件不是财务凭据。既有素材扫描器会重编码并剥离元数据，下载验证比较了解码像素。
7. **老板账本：已通过。** 使用同样的金额层级与日期格式，保持只读。没有登记输入或写入动作。合同金额和费用金额使用准确标签，避免将合同总额误写成剩余待收。
8. **业务与工程衔接：已通过。** 业务申报收款后未直接产生实收，财务核实才入账；工程提交材料计划，财务登记采购金额和公司付款，工程端读取已付及余额。工程个人垫付被拒绝；设计费允许业务已垫付，由财务办理报销。

控件字号、触达区域与阅读顺序已在模拟器中检查；未据此声称通过完整无障碍或所有手机设备认证。

## 修复的功能问题

- 财务统计没有兼容接口实际返回的时间戳和日期数组，导致有收付款而首页显示零。现在统一按中国时区的业务日期归月，空日期仍不计入月份。
- 账本及报销路由未登记，部分入口回到首页；账本范围参数未解码，点击列表后无法取数。两处均已修复。
- 账本列表与原有空状态重复渲染、英文状态和技术来源串直接露出，均已清理。
- 财务首页混入尚未实际发生收款的合同阶段，重复形成办理待办。财务改由到账申报待核实与真实应付、报销事项产生待办，合同未收款保留在应收查询。
- 员工退款归还后待办未计入已归还额，已修正并补充回归。
- 付款选择器保留真实来源类型，工程采购不显示个人垫付选项；后端权限约束仍有效。
- 接口失败时保留“—”及错误状态，不能把未知财务金额格式化为零。

## 对标与实现选择

财务场景参考畅捷通公开资料的按期间查账方式；移动交互参考成熟组件的弹层、取消与确认模式。本次实现为可复用的原生小程序 `month-select`，按年切换、12 个月网格点选，不额外引入整个组件库。

- [畅捷通官方账簿说明资料](https://service.static.chanjet.com/cjt/2022-08-01/165932235630.pdf)：公开资料用于核对期间查账场景，不代表其最新版手机界面的实测。
- [TDesign 日期时间选择器](https://tdesign.tencent.com/miniprogram/components/date-time-picker)
- [Vant Weapp 日期选择实现](https://github.com/youzan/vant-weapp/blob/dev/packages/datetime-picker/index.ts)
- [Ant Design Mini 日期选择器](https://mini.ant.design/components/date-picker/)
