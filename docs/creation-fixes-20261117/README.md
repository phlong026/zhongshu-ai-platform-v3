# 飞影媒体兼容修复（2026-11-17）

发布版本 `1.0.20261117.1159` 已通过微信官方工具上传，用户确认已设为体验版；后台切换状态来源为用户反馈，未独立进入微信后台复核。保留当前已上传 `.1052` 运行文件，仅合入媒体上传相关变更，未提审或正式发布。

- 修复跨 JS 上下文 ArrayBuffer 的 SHA-256 类型识别，增加分块摘要；500MiB 输入按1MiB读取，不为摘要复制整份视频。
- 支持 MP4/MOV 视频和 MP3/M4A/WAV 声音；按文件格式申请飞影凭证，严格使用返回 MIME，素材直接 PUT 飞影，不进入平台云存储。视频500×1024²字节、声音20×1024²字节边界前后端一致。
- 原上传按钮增加视频来源选择，提供相册/拍摄和聊天文件入口；保留微信相机60秒录制限制，相册及文件按5秒～30分钟检查。检查可读取的时长、分辨率和已识别的HEVC；未能识别的实际编码仍由飞影最终校验。
- 保留现有IP、分身、声音及“文案二创→数字人口播”布局和业务入口。上传过程显示检查/摘要/上传状态，读取和网络失败给出可理解提示。
- 字幕使用 `st_pos_x/st_pos_y`，旧 `st_x/st_y` 兼容映射；校验文案HTML、长度、字幕数值/颜色及参数冲突，在预占积分之前拒绝非法参数。
- 区分凭据失效、超限、不支持格式、资源读取失败、声音数量上限和结果未知。明确拒绝释放预占，网络结果不确定不自动重投；平台用户登录不因供应商凭据问题被退出。

验证：内容域163项后端测试全部通过（包含真实隔离PostgreSQL）；冻结发布包 `npm run check` 全部通过；创作链专项54项通过，新增500MiB分块摘要独立校验后摘要/格式组8项通过。官方上传主包1,916,019字节，完整包7,706,991字节。

后端按当前B运行包增量部署，只替换内容模块相关类，其他模块保留；无数据库迁移，私有备份与回滚版本保留，健康检查UP。详见部署回执。

实际飞影MOV/M4A/WAV上传凭证已核验，分别返回video/mov、audio/m4a、audio/wav；没有上传真实媒体或提交付费制作。500MB真机传输、真实克隆和成片验证按用户要求继续暂停，不能据本次自动化测试认定所有手机都可稳定上传500MB视频。
