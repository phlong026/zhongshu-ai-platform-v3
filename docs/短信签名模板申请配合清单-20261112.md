# 短信签名/模板申请配合清单（2026-11-12）

> 目标：补齐员工短信登录通道（后端 `PF_SMS_SIGN_NAME` / `PF_SMS_TEMPLATE_ID` 两值）。
> 契约已核对：`TencentSmsClient` 按签名名称+模板ID 发送，模板必须含 `{1}` 占位（验证码单参数）；验证码 5 分钟有效（`SmsCaptchaService.CAPTCHA_TTL`）。
> 控制台路径：腾讯云控制台 → 短信 → 国内短信 →（实名资质管理 / 签名管理 / 正文模板管理）。

## 一、第一步：实名资质报备（签名申请的前置，材料齐后约 2 小时过审）

表单路径：国内短信 → 实名资质管理 → 添加资质。可预先填好的文本：

| 字段 | 填写值 |
|---|---|
| 资质名称 | `众墅之家短信资质`（无固定要求，仅标识用） |
| 资质属性 | **自用**（签名所属主体=本账号实名主体，默认已选） |
| 企业证件类型 | 营业执照 |

必须上传的材料（png/jpg/jpeg ≤5MB）：

1. **营业执照**：加盖红色企业公章，系统自动识别信息（识别不准可手动改）
2. **企业法定代表人身份证**：人像面+国徽面，**复印在 A4 纸上加盖企业公章后拍照**（正反面可同图）
3. **短信业务管理员身份证**：人像面+国徽面（同样复印盖章）**+ 手持身份证照片**（手持照无需盖章）
   - 管理员可与法人为同一人（材料复用，但手持照仍必须提供）
   - 注意规则：不同公司主体的管理员不能是同一人
4. **安全合规使用承诺书**：表单页有"下载承诺书"链接 → 填写日期 → 盖企业公章 → 拍照上传
5. 其他资料：选填，可不传

## 二、第二步：创建短信签名（资质过审后提交）

| 字段 | 填写值 |
|---|---|
| 签名类型 | 企业 |
| 签名内容 | **众墅之家**（小程序名"众墅之家赋能平台"的关联简称；后端发信显示为【众墅之家】） |
| 佐证材料 | 小程序：上传已备好的截图 [docs/短信签名佐证-小程序信息-20261112.png](./短信签名佐证-小程序信息-20261112.png)（mp 后台账号设置页，含小程序名称与主体信息） |
| 关联资质 | 选择第一步过审的"众墅之家短信资质" |

## 三、第三步：创建正文模板

| 字段 | 填写值 |
|---|---|
| 模板类型 | 普通短信 |
| 模板名称 | `登录验证码` |
| 模板内容 | `您正在登录众墅之家赋能平台，验证码{1}，5分钟内有效，请勿泄露。` |

**红线**：`{1}` 是唯一参数位（后端只传验证码一个参数）；内容含有效时长是审核要求；不要出现"测试/demo"字样。

## 四、审批通过后回填（给我这两个值即可）

- `PF_SMS_SIGN_NAME=众墅之家`
- `PF_SMS_TEMPLATE_ID=1xxxxx`（模板 ID 数字）
- 入 `.env` 后即可跑 `script/cv-e4-sms.py` 完成真实渠道验收

## 五、时间预期（重要）

- 资质审核：约 2 小时（工作时间 9:00-21:00）
- 签名：腾讯云审核后**自动提交运营商报备，需 7-10 个工作日或更长**（2026-11 新规）——这是当前上线链条上**周期最长的外部依赖**，材料今天齐 today 提交
- 模板审核：通常数小时内，快于签名
