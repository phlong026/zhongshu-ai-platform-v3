# 课程资料上传状态与可用性修复

2026-11-16 已发布到[正式管理后台](https://platform.zszhj.com/admin/training/materials)。

## 问题与原因

后台上传一支 15 秒 MP4 后，弹窗停留在“上传完成，等待处理”并显示绿色打勾。生产数据库核对显示，文件已经完成 FFmpeg 转码，版本状态为 `READY`，播放文件和封面均已生成；问题来自管理后台前端：

- 分片上传结束后立即把任务显示为“完成”，没有等待后台转码完成。
- 页面没有轮询已存在上传任务的处理状态。
- 处理完成后没有刷新到所选分类、选中新资料并收起上传弹窗。

## 修复内容

- 上传任务新增“上传中 → 处理中 → 可用”状态链；转码期间显示旋转状态和已用时间。
- 前端通过现有 `GET /training/admin/uploads/{id}` 接口轮询 `processing_state`，只有收到 `READY` 才标记完成。
- `FAILED` 时展示服务端错误并允许重新排队处理；状态查询短暂失败会自动重试。
- 处理完成后自动切换到上传时选择的资料分类、刷新资料库、选中新版本。
- 当前批次全部处理完成后自动收起上传窗口；单文件正在上传时关闭窗口仍会提示确认，纯后台处理中则允许安全关闭。
- “处理中”计入未完成任务，课程发布前仍会阻止使用未完成资料。
