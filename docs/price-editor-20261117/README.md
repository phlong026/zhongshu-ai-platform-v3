# 当地单价输入框样式修复（2026-11-17）

开发版 **1.0.20261117.1724** 已上传，基于 1.0.20261117.1638 的固定版本，仅更新当地单价页面的 WXML、SCSS、WXSS 以及明确的分组数量渲染状态。此轮不涉及后端部署或生产单价修改。

问题：编辑状态把项目说明、300rpx 输入框和保存/取消挤在同一水平行；input 没有显式高度且有上下内边距，导致原生控件文字被裁切，说明区域被挤窄，单位也被拆行。

修复：

- 编辑状态分成项目说明、整行价格输入区和按钮区；长名称不被输入框挤窄。
- 输入框外层 96rpx、至少 48px；原生输入控件 88rpx、至少 44px，取消上下内边距。
- 单位固定在输入区域右侧，保持整段展示。
- 保存/取消位于单独一行，触控高度至少 44px；保存过程中禁用取消，避免提交未完成时关闭编辑。
- 明确使用 groupCount 更新分组渲染，避免只依赖数组 length 的条件更新。

原生模拟器测量：控件高度 45px，外框 49px，输入宽度约 249px；说明区域宽约 330px，保存/取消各高 44px。数字 520.00 和 1234.56 均完整显示。保存 1234.56 按 123456 分提交、保存后回显正确；取消未保存的 888.00 后仍保留 1234.56；长项目名称可正常换行。

UI 测试使用独立测试 AppID 和模拟价格接口，没有修改生产价格；未进行 Android/iOS 真机验收，需使用本次开发预览继续手机测试。现有相关回归 50 项通过，最终包的资源引用和大小检查通过，上传文件哈希复核一致。
