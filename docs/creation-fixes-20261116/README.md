## 链接提取

原流程把链接解析结果的 `text` 当作完整文案。抖音解析返回的是发布简介和话题，导致尚未转写口播就进入二创页。现在先解析媒体，再用音频地址（没有有效音频地址时用视频地址）调用现有转写接口，仅将转写结果写入二创页的“原文”文本框。

支持从整段分享内容中提取 URL，兼容用户示例中的 `https\://`、转义斜杠及句尾标点。解析和转写分别显示处理阶段。失败、空结果和待核实状态不会覆盖已有草稿；重试沿用原解析及转写请求键。

## 人物库

原来的分身和声音制作表单依赖先选中人物卡片，空列表时完全没有入口。现在顶部固定显示“口播分身”和“语音克隆”两个选项。

- 老板、公司负责人及业务负责人：空库点击选项后先新增人物，保存成功后根据服务端返回的人物 ID 自动进入对应制作流程。
- 已有人物：直接打开对应选项，可切换所属人物；同名人物仍使用精确 ID。
- 普通业务员：两个入口仍可见，空库明确提示联系管理员准备资源；沿用现有后端权限，仅选用资源。
- 原有 MP4 人物视频、MP3 声音样本、授权确认、积分报价和同笔制作重试流程保持接入。
