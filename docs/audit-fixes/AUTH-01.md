# AUTH-01：初始凭据与密码入口统一

员工逐个开户改为复用随机 16 位初始密码；新初始凭据有效期为 48 小时，只交付当次响应，首次改密后不可重用。

## 存量与恢复

- 新增 Flyway `V20261122.990`，只退役仍 `require_change=true` 且具有 STAFF 别名的用户初始凭据；同一人员后来也取得 BOSS 别名仍需退役。
- 已自设密码、正常复用的旧账号和仅有 BOSS 别名的账号不重置。迁移按 tenant/user 联合匹配。
- 旧可预测 hash 写成 BCrypt 不接受的退役标记，同时将初始有效期置为过去；回滚旧应用也不会重新接受该密码。不能通过回滚迁移恢复初始密码。
- 官方微信登录在身份与有效岗位检查成功后退役未使用初始密码，包括之前已绑定微信的用户再次登录；后续微信登录不重复改正常密码。
- 初始凭据过期/退役后仍可用官方微信登录。需要恢复密码登录时，使用现有手机号验证重置或已授权管理员重置；成功写密码后清初始状态。普通开户复用旧账号不会擅自重置其密码。

## 通道与并发

底座用户名密码入口通过 `AdminUserPasswordPolicy` 扩展执行平台初始状态检查，不能绕过小程序首次改密。系统密码修改和微信退役与首次改密使用相同锁序：policy 行 → 用户密码。失败修改不会清初始状态。

## 回归

新增/调整场景置于现有 CI 会执行的 `FranchiseAccountAuthServiceIntegrationTest` 和 `StaffWechatLoginIntegrationTest`：随机凭据、旧规则拒绝、48 小时默认/过期拒绝、底座入口、可信重置与失败保留、已有微信绑定退役、正常密码保持，以及真实迁移的用户范围与跨 tenant 隔离。

本地运行需要 Maven/JDK 与 PostgreSQL/Redis；没有这些工具时不能把静态检查视作已运行集成测试。合并前以对应 PR 的 Backend CI 结果为准。

## 存量已改密账户保护补修

历史短信找回、系统管理员重置与个人资料改密可能只更新了 BCrypt hash，未清除 `require_change`。
该标记不能单独证明当前密码仍是初始密码。新增 `V20261122.989` Java 迁移，复用现有 Spring Security
BCrypt 校验并由现有 `classpath:db/migration/pf` 自动发现，在原 `V20261122.990` SQL 之前执行：

- 按 tenant/user 锁定策略和用户行，核对这个用户的全部 STAFF 正式登录名与历史 `login_name + "123"` 算法。
- 只有完整有效的 BCrypt hash 且不匹配任一历史初始密码时，才清除过时的 `require_change`；密码 hash 原样保留。
- 任一 STAFF 身份仍匹配弱密码、无法识别的 hash 或不符合历史规则的登录名都不作为已改密放行。只有 BOSS 身份的账户不受此保护迁移影响；STAFF 后兼任 BOSS 仍检查 STAFF 凭据。
- 所有写入在该迁移事务内执行；错误整体回滚。迁移不记录密码、hash、手机号或完整账户信息。
- 原 `990` 文件保持原字节和校验和。它仍为已改密账户补上列的默认值，但 `require_change=false` 时该初始期限不参与登录判断；以后正常改密会将该值清空。

B 的现有 `pg` 配置启用了 `spring.flyway.out-of-order=true`。已运行 `990` 的数据库会补登记 `989`，
但只要初始期限列已存在，保护迁移即不修改任何密码或策略，避免误处理升级后新建的随机初始凭据。
不得通过跳过迁移、修改旧校验和或回退版本使已退役弱口令重新可用。

### 旧 990 已执行后的恢复

`!retired-initial-password` 不包含原 hash，后置代码无法从该标记恢复先前密码，也不能判断其中哪条原为正常密码。
受影响人员仍可通过现有官方微信手机号授权登录；恢复密码登录必须使用已验证手机号的找回流程，或由有权限的管理员
按既有受控重置流程设置新密码。成功重置后才清初始策略。不要把姓名、登录名或标记本身当作重置凭据；不要生成或公布
一批通用恢复密码。若需核对影响范围，可由受权运维在隔离的升级前备份中比对，禁止用备份覆盖当前库或回填旧可预测密码。

回归置于现有固定 CI 类 `FranchiseAccountAuthServiceIntegrationTest`：真实 Flyway 自动发现及顺序、三类旧重置状态的
hash 原样保留与 Web/小程序密码登录、全部 STAFF 别名、tenant/BOSS 边界、错误回滚/重试，以及旧 `990` 已执行库中
退役标记和新随机初始密码的保留及受控恢复。发布产物检查同时列入 Java 迁移的字节摘要，防止迁移清单只覆盖 SQL。
