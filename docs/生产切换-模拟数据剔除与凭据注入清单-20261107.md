## 二、生产部署必注入凭据（缺失即拒绝启动）

以 `--spring.profiles.active=pg,prod` 启动时，以下环境变量缺失/占位会被
`RealServiceWiringPolicy` 启动守卫拒绝：

| 环境变量 | 说明 |
|---|---|
| `ZS_PG_URL` / `ZS_PG_USERNAME` / `ZS_PG_PASSWORD` | PostgreSQL 连接 |
| `ZS_REDIS_HOST` / `ZS_REDIS_PASSWORD` | Redis（PORT 默认 6379） |
| `ZS_INTERNAL_SECRET` | internal API 请求签名密钥 |
| `ZS_ACCESS_CODE_PEPPER` | 授权码哈希椒盐 |
| `ZS_ACCESS_CODE_ARTIFACT_KEY` | 授权码票据密钥（Base64 32 字节） |
| `ZS_WX_APPID` / `ZS_WX_APPSECRET` | C 端微信登录（provider=real） |
| `ZS_COS_ENDPOINT/REGION/BUCKET/SECRET_ID/SECRET_KEY` | COS 对象存储五件套 |
| `ZS_MODERATION_SECRET_ID/SECRET_KEY/BIZ_TYPE/DAILY_LIMIT` | 内容审核 |
| `PF_SMS_PROVIDER=real` + `PF_SMS_SDK_APP_ID/SIGN_NAME/TEMPLATE_ID/SECRET_ID/SECRET_KEY` | 腾讯云短信（pg 基线默认 stub，prod 必须 real） |
| `ZS_XPAY_OFFER_ID/APP_KEY/PUSH_TOKEN` | 微信虚拟支付道具 |

行为开关：`ZS_CONTENT_TASK_SWEEP_ENABLED`（已写入 prod yaml 默认 true，可注入覆盖）。

**已关闭（用户可达，或会挡住正式岗位办理）**

- 工程记录 `writeRole` / `financeRole`、项目列表「新建」改为读 `currentApiPost()`。演示登录删除后 `X.context().role` 恒空，工程人员看不到开工/节点/交付，财务看不到收款登记。
- 工程 Tab：API 工程岗进入 `/pages/build/home/index`，不再等本地演示身份。
- 财务台默认视图按 API 岗位打开工作台首页；总部账本默认应付。原先用本地 `orgType` 判断，正式财务会落到收支列表。

- 内容获客页：API 门店销售家族可进。本地 `G.load()` 在无演示会话时返回空列表，不注入种子；平台总览与待关联客资仍走接口。
- 文案：未开通的工程动作不再提示「请在本地演示态查看」；内容接口失败不再声称「已保留本机内容」。
