微信一键登录已修复。按用户授权追加业务员、工程人员、财务专员任职，保留老板任职；四个岗位均已在开发者工具切换巡检，收尾恢复老板工作台。

## 实测结论

- 登录：只更正员工小程序凭据配置，受控重启一次共享服务。微信登录业务码0、有效任职和工作台落地成功；两域名健康均HTTP200/UP，JAR未替换。
- 页面：本轮166条导航/观察记录，覆盖21个实际承载路由及多个view/表单，并核验部分兼容入口；这些数字不是通过用例数。35个注册路由的具体覆盖与未验证原因见[覆盖表](page-coverage.csv)。
- 确认缺失：公司积分summary、my-usage在当前运行实例均为HTTP200 + 业务404。
- 确认不匹配：获客汇总把对象当数量；作品/发布记录页未调用已有列表API；添加成员接口500；设计流程的无权限路径触发platTeardown错误。另有账户设置门禁和加载提示残留。
- 当前后端仍是11月10日融合包；独立B源码映射不等于当前运行版本全量可用。
