## 二、"空页"43 项为误报

- 41 项在 `pages/build/index`（工程各视图）：页面由模板渲染，脚本按页面 wxml 里的类名取元素时取不到。用渲染快照核对，这些页面在有项目数据时都有完整内容（如施工进度、材料计划）。
- 2 项在 `admin/home`、`admin/finance`：由组件渲染。已截图确认页面内容完整。

## 三、P0 点击区域：已整改（全部用公共样式）

问题集中在这些控件类型，已用 `styles/unified.wxss` 里"每种控件一条规则"统一解决，没有给单页新增类：

| 控件类型 | 页面 | 规则 |
| --- | --- | --- |
| 分段标签、选项按钮、设置行按钮 | 客户工作区、案例详情、责任转交、AI 平面/立面配置 | 最小高度 88rpx |
| 输入、选择器、多行输入 | AI 配置页尺寸输入、方案探索筛选 | 最小高度 88rpx；多行输入 160rpx |
| 列表行 | 客户列表 | 最小高度 88rpx |
| 紧凑操作按钮 | 业务首页待办、客户行"去办理"、方案页入口 | 最小高度 88rpx |
| 轮廓按钮、上传按钮 | 工作流页 | 最小高度 88rpx |
| 账号页行、课程行、输入 | 我的、帮助与反馈、课程 | 最小高度 88rpx |
| 工程记录页入口行 | 施工节点记录 | 最小高度 88rpx |

注：88rpx 在 375px 宽的屏幕上是 44px，达到微信建议的最小触控高度。

整改后复测：上面 16 个页面，P0 已全部清零；业务首页、客户工作区、方案探索、案例、责任转交、AI 配置、帮助与反馈、登录、身份页均为 0 项问题。

## 五、测量说明

- 脚本测的是元素框，文字大小、对比度以源码扫描为准。
- 游客 AppID 副本与正式 AppID 的页面、布局一致，但不涉及真实登录和云能力。
- 正式 AppID 当前登录账号不是该小程序开发者，开发者工具无法用正式 AppID 打开项目，需要重新登录有权限的账号。
