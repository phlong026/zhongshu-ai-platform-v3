# 设计委托面积计价与模拟支付

本轮按用户确认的体验范围实现，不接真实支付商户，不发生真实扣款。“供应商财务”在本项目指加盟商（门店）财务。

## 业务规则

1. 总部设计人员在“我的 → 设计费计价设置”设置每平方米单价、适用交付范围及收款方，保存新版本。没有启用规则时提示配置，不能使用隐含默认价格。
2. 经办业务完成预算后提交设计需求。计费面积取本客户有效预算的建筑面积；费用按面积乘总部单价计算到分。页面不能手工覆盖费用。
3. 同一次提交保存需求、预算版本、计价版本和一次性支付订单。交付范围须匹配总部规则，不增加首款/尾款申请和老板逐单审批。历史首尾款委托继续沿原流程。
4. 经办业务选择微信或支付宝体验模拟支付。取消或失败保持原订单待支付，可重试。成功后同一订单只形成一笔成功记录；改价不改变已有订单金额。
5. 支付成功自动抄送门店财务、总部财务，同时生成总部设计待办。双方财务的模拟记录只读，明确标记“体验模拟”，不计入正式实收、实付；不需要登记付款和确认到账来再次解锁设计。
6. 总部设计完成设计和内部审核，使用本项目模拟文件提供正式成果、施工图、审核依据及图纸版本，下发给经办业务。
7. 业务接收总部本版文件，补客户确认凭据、确认日期和现场交底，整包移交工程。文件和版本须与总部下发相同。
8. 工程接收后自动创建唯一工程项目，带入五项资料，接续开工准备待办。

## 责任与衔接

| 节点 | 责任岗位 | 完成后的接续 |
| --- | --- | --- |
| 配置单价 | 总部设计 | 业务提交页显示有效计价 |
| 需求与委托 | 门店业务 | 本业务获得一次性支付入口 |
| 模拟支付 | 门店业务 | 双方财务抄送；总部设计待办 |
| 财务抄送查看 | 门店财务、总部财务 | 只读核对，无重复审核门禁 |
| 设计完成 | 总部设计 | 上传并下发成果待办 |
| 上传下发 | 总部设计 | 门店业务收图与移交待办 |
| 客户确认及整包移交 | 门店业务 | 工程核查接收待办 |
| 核查接收 | 工程负责人 | 工程项目自动建档及开工准备 |
| 历史例外费用审核 | 加盟商老板 | 仅保留旧首尾款流程的例外审批；本轮标准面积计价不新增逐单审核 |

## 数据与支付边界

计价和订单均保存版本，付款成功记录绑定客户、项目、预算、委托及服务版本。总部下发文件沿用同一项目和图纸版本。模拟支付仅开放体验身份且正式发布环境禁止办理，不创建真实微信/支付宝交易。新链路的需求附件、总部成果及客户确认均使用带本客户、项目、图纸版本和可预览内容的模拟文件，页面不要求选择本地文件。正式文件接入在真实服务后续实现。

后续真实支付需另接服务端下单、商户密钥配置、签名验签、异步通知、金额核对及查单。微信官方要求不能仅凭前端调起结果判定实际收款：[微信支付小程序支付指引](https://pay.wechatpay.cn/doc/v3/merchant/4012791911)。本轮不使用真实支付成功回调。
