# 设计行政工作台与到账联动

## 页面与职责

设计行政采用“首页、项目、我的”三项导航。“项目”覆盖该总部设计组织负责的全部已授权委托，包括设计、修改、待到账确认、待下发、已下发及后续移交完成的历史记录。

首页顺序与业务首页一致：问候语和日期、设计与修改／待到账确认／待下发三张统计卡、今日待办、最近办理。今日待办只显示当前人员可直接办理的事项，预览三条并显示完整数量；最近办理取当前人员真实完成和下发事件，最多五个项目。等待加盟商付款或总部财务核实的项目不计入今日待办。

项目支持客户、项目编号、加盟商、城市及经办业务搜索，提供六个状态筛选；设计与修改统计卡进入组合筛选。切换首页和项目保留搜索条件。首屏20条，每次加载20条，总数基于完整授权集合；再次进入页面重新读取业务状态。

详情保留尺寸依据与需求附件，复用设计完成、下发、修改和移交表单。操作区随内容滚动。行政页面仅显示付款是否满足放行条件，不输出客户电话、微信、费用金额、银行流水或财务凭证。

## 到账后自动接续

用户明确由**总部收款财务确认实际到账**。加盟商登记已付款与总部确认已实收分别保存，不能互相替代。

1. 老板费用授权通过后，自动生成加盟商首款付款待办；行政即可安排线下设计。
2. 加盟商财务在原单登记实际付款，自动生成对应总部的到账确认待办，关联原付款、委托、需求版本、服务版本和款项阶段。
3. 总部财务在“确认设计款到账”核对银行流水、实际金额、实际日期和凭证，一次保存为实收。支持分笔确认，剩余差额继续保留待办，不增加另一轮复核或“通知行政”按钮。
4. 行政点击“设计完成”后，立即生成业务尾款跟进及加盟商财务尾款付款待办，不再申请尾款或重复老板审批。
5. **设计完成、当前修改已处理、当前版本首尾款均由总部确认足额到账**时，自动转为“待下发”，进入行政今日待办，并生成对应人员的未读站内消息。到账先于设计完成时，在设计完成后自动接续。
6. 行政实际下发正式成果并登记后，原下发待办关闭，业务自动收到“收图并移交”待办。原消息可查看办理记录。

首款到账不额外限制设计启动，沿用已批准的业务规则；正式成果下发同时核验本版首尾款。行政表单已删除“收到财务线下通知”勾选，只保留对实际设计完成或实际下发的确认。

## 原单、金额与通知约束

- 金额使用整数分；每笔到账不超过对应原付款剩余可确认金额。少一分钱不会放行，分笔记录累计有效实收。
- 命令层重新校验在岗总部财务、收款组织、付款来源、需求及服务版本和表单打开时的剩余金额。银行流水重复、旧页面重复提交、旧费用版本及其他组织记录不能放行。
- 撤销、更正和已核实退款按净额重算。未足额时关闭下发入口并恢复差额到账待办；后续补款再次足额，生成新的未读通知。已经实际下发的历史记录保留，不伪造撤回图纸动作。
- 下发命令再次校验放行条件，并保存当次需求、服务版本与不含金额及银行资料的到账确认版本，防止绕过页面。
- 设计款实收保存在原总部账簿，不另造客户合同收款，避免重复统计。总部只查看本组织实际到账凭证；行政只查看放行结果。
- 通知按人员和组织隔离，已读互不影响。状态和通知从已保存原单推导，不单独写一份易失真的“财务已通知”标记；保存失败不会提前产生下游待办。

## 实现与复测

`utils/design-receipts.js` 复用原账簿办理到账、分笔和放行；`utils/transfers-v2.js`、`utils/authority-v2.js`、`pages/admin/finance-actions.js` 接入原财务入口；`utils/sales-flow.js` 执行下发门禁；`utils/design-notifications.js` 和账户消息页提供站内消息。未新增依赖或数据库表。

```sh
npm run check:design-admin
npm run check:design-receipts
npm run check:business:simplified
npm run check:design-receipts:native
```

到账专项覆盖权限、组织、分笔、精度、版本变化、重复提交、保存失败回滚、退款补款、消息隔离及命令层阻断。原生连续流程使用隔离微信开发者工具副本、模拟人员及示例凭证；结果和截图位于 `qa/design-receipts-20261022/native/`，结束后恢复原存储。工作台原生记录位于 `qa/design-admin-workbench-20261022/native/`。

## 当前交付边界

当前应用仍使用本地存储。自动待办和站内消息已在共享同一数据状态的本地模型与原生模拟器内接通；不同手机真实协作仍需后端持久化、服务端权限及到账校验、事件同步和消息发送。微信订阅消息与银行自动对账未接入，总部仍需人工核实真实银行到账。没有发生真实付款或发送正式图纸，未上传或发布微信版本。
