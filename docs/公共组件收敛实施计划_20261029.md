# 公共组件收敛实施计划

## 行为基线

- 搜索框继续把原生 `input` 的 `detail.value` 传给页面，清空动作仍调用各页原有处理器。
- 工程待办继续由页面的 `openAction` 办理，`data-action` 保留在组件节点上。
- 空态只替换纯展示结构；含多按钮、条件分支或业务表单的空态保持页面私有实现。
- 统计卡只迁移无图标、无单卡特殊提示的同构摘要；业务首页、老板首页、工程快捷入口保留各自产品语义。
- 页面已有 `brand-header`、`business-header` 和 `action-panel` 继续作为头部与通用弹层单源；不为数字强行新增套壳组件。
- Node 页面回归运行时只展开本批四个无状态组件，并验证属性、宿主 `data-*` 与自定义事件代理；不伪造复杂组件的微信渲染器行为。

## 实施顺序

1. 先增加结构回归，锁定组件事件、关键属性和迁移页面。
2. 新增 `search-box`、`todo-row`、`empty-state` 三个小组件。
3. 迁移业务、工程、管理搜索；工程今日待办；管理、老板、绩效等纯文本空态。
4. 扩展 `stat-grid` 的只读摘要模式，迁移管理经营摘要。
5. 运行组件回归、静态包检查及相关页面回归。

## 明确保留的页面私有实现

- 业务首页统计卡含图标、逾期红点和三种去向，不改成基础 `stat-grid`。
- 工程快捷入口含图标和动作语义，不改成基础 `stat-grid`。
- `build/index`、`workflow/index`、`account/index` 的弹层含大量专属表单及状态机，不改成 `action-panel`。
- 客户卡、财务原单、工程项目卡字段与权限动作不同，不强行合并为一个 `list-row`。

## B7-3/4 最小收敛面

- `list-row` 仅收敛 `admin/operations` 中三类同构 `ops-link`：今日待办、项目账目、原单应付。行内容继续由默认插槽承载，宿主 `data-url/data-view/data-id` 和原 `go` 处理器不变。
- 四种头部保留各自适配器和产品语境：`brand-header` 保留品牌标志与根页判定，`business-header` 保留业务设计流，`creation-header` 保留像素导航高度，`owner-header` 保留老板首页布局。只把固定子页定位、44px 点击区、返回/工作台避让和标题截断收进 `subpage-navigation.wxss`。
- `action-panel` 仅接管两页中不承载表单的部分：`admin/index` 的凭据预览，`account/index` 的通知、方案预览、退出确认和演示进度确认。财务确认和登录弹层保留原页面节点，避免改变已有原生验收选择器；原因输入、课程内容、取消决策、付款回执、客户选择、支付台和文档预览仍保留页面状态机。

### 弹层不等价清单

- `admin/index` 财务确认保留 `.sheet .solid`，现有财务原生验收依赖该页面选择器；`reason` 还需把 `data-key="note"` 传给原 `input` 处理器。
- `account/index` 的 `login-demo` 保留 `[data-handler="confirmModal"]`；`lesson` 包含课程图和完成语义，`cancel` 需原因，`cancel-resolution` 还有结果选择、凭证上传和核对勾选，`paymentReceipt` 是独立付款回执。
- `build/index` 的 sheet 由 `sections` 模板、多类表单、动态确认词和 `modalSubmit` 状态机组成。
- `workflow/index` 同一 sheet 承载登记、编辑、跟进、派单、退回、收款、生成和外装配置，并分流 `saveModal/closeModal`。
- `workflow/explore` 是客户选择器；`workflow/commission` 的收银台、客户确认、文档预览各有专属回写，且预览关闭已有 `.commission-mask .commission-primary` 原生验收入口。
- `creation/index`、`studio/index` 的 sheet 是文案编辑、形象/声音/封面/账号选择器；`ai-video/index` 是素材库选择器，均不是单次确认面板。

## 主线整合后的页面边界（2026-10-30）

管理 Tab 已改为老板/财务角色直达。原中转页搜索和经营摘要随该页退役，相关组件注册及测试断言已删除；统计组件仍保留已有基础卡与只读展示契约，独立财务首页沿用自身指标办理语义。
