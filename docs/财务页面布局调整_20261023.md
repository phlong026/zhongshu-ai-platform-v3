# 财务页面布局调整与核查

## 调整结果

财务页面已改回项目现有的暖色工作台风格：米白页面、白色紧凑卡片、棕色文字按钮和细分隔线。没有新增布局抽象，也没有改变财务权限、金额计算或原单办理流程。

财务首页严格按以下顺序展示：

1. 欢迎语、姓名和当前月份
2. 财务数据
3. 待办事项
4. 常用快捷办理
5. 正在办理

第五区之后不再追加身份、说明或其他业务板块。身份切换继续使用现有页头账号入口。

- `miniprogram/pages/build/home/index.wxml`、`miniprogram/styles/engineering.wxss`：欢迎语、日期、数据卡、待办、常用功能和最近项目顺序。
