# 加盟商财务实施与测试记录

日期：2026-11-17

本次完成首个可用版本的核心代码调整，范围覆盖小程序、Java后端、老板经营汇总和PC财务查询。代码复用原收款、付款、应付、退款、设计结算、统一合同实收和工程采购，不另建现金事实表。

当前状态：本地代码及下列自动化检查通过；未部署生产，未对生产业务数据执行迁移。微信实机视觉验收与线上多岗位联调尚未完成。原方案中的条件扩展、存量核对和发布步骤不能据此视为全部完成。

| 补记 | 项目/公司归属、分类、对方、实际日期、账户、凭据；零星费用/应付与付款事务内一次办理 |
| 设计垫付 | 原付款区分公司支付与员工个人出资；设计费沿原单登记个人垫付，财务也可补记实际小额垫付；正常工程材料采购原单由公司付款 |
| 报销 | 自动形成员工往来；分次报销；退给员工及退回公司区分；员工应还款可以登记实际归还 |
| 到账协作 | 业务、工程提交到账信息不产生实收；财务确认才沿原合同收款；资料错误可退回补充并重新申报 |
| 定金抵扣 | 已存在的一笔手工实际收款可以整笔认领到一个合同期次，不新增实收；关联防重复 |
| 合同变化 | 确认增减项后调整期次及总额；可增加交付后尾款及约定到期日；原款项保留 |
| 工程交付 | 交付资金条件使用当前合同交付前约定，交付后尾款单独保留；技术节点要求继续生效 |
| 采购退料 | 财务可依据确认结果调整采购/费用结算总额，退款仍引用原付款；工程材料汇总同步读财务结算金额 |
| 补资料 | 原收付款补凭据/说明单独留痕，不新增费用或付款，不占用原资金修订版本 |
| 真实待办 | 到账核实、采购付款、设计报销；退回资料进入原申报人待办，重新申报后旧退回事项结束 |
| 老板与PC | 老板现金排除员工个人出资；待收按统一合同逐期计算，待付与账龄使用同一余额；PC增加账本及员工往来查询 |
| 异常付款 | 待分配的超付款不冲减其他应付；退回未分配部分不重新制造供应商欠款；现金仍按全额实际收付 |

设计费2400元的验证结果：员工支付时公司现金0、待报销2400；公司分报1000与1400后公司现金累计2400、费用不重复。报销后平台退给员工500，显示员工应归还500；实际归还后往来结清。

## 复用及新增接口

继续使用原 /franchise/finance/receipts、payments、payables、refunds、expense-refunds、projects/{id}/ledger、设计费用和银行匹配接口。

新增 /franchise/finance/workbench 下的账本、关联工程、组合登记、报销余额、员工归还、归属补充、结算调整及补凭据接口；所有写操作使用幂等键、公司对象校验和事务。

业务新增到账申报确认/退回、合同财务期次、合同金额调整及原收款认领接口。现有collect调用对非财务岗位转为申报，对财务岗位继续实际登记；工程不会把未确认申报写成一笔实收。

新增员工出资类型不会改变模拟收银台和积分的性质。业务模拟支付仍不进入真实人民币收支，也不会自动生成真实报销。

## 仍保留的范围与限制

1. 设计费使用原设计事项；其他已发生小额垫付由财务补记。业务员工自助报销表单尚未开放，财务根据真实出资人及凭据办理；正常材料采购保持公司付款。
2. 定金目前支持一笔原收款整笔认领一期；一笔收款拆给多期/多个项目、合并付款的跨项目分摊尚未开放。
3. 业主代付抵工程款、总部材料代垫、备用金、押金专门结清及公司账户内部调拨属于原方案按实际场景启用的扩展，本次未启用。不能用普通收入/费用登记假装这些业务已经正确结清。
4. 项目账当前显示最近500条并提示截断；PC原账表筛选与导出继续沿原接口，新增账本维度的完整专用导出仍需补充。
5. 历史空归属、未知日期、旧员工垫付及期初余额需要核实后处理。本次不按姓名、金额猜测合账，也不把所有空项目记录直接转成公司费用。
6. 新增待办以实时查询为主；手机实际显示、按钮可达性、跨岗位点击联调与消息体验仍需在联调环境验证。

## 数据库与发布顺序

新增迁移为 V20261117.943__finance_workbench.sql 和 V20261117.944__sale_finance_confirmation.sql。结构采用新增表/列及默认值；原付款默认COMPANY，已有资金不因增加归属而复制。

先部署包含两个迁移的后端，再同步小程序和PC端。不能先发布依赖新接口的前端到旧后端。正式数据迁移前，应核对现有收付款总额、空归属、待分配金额及疑似重复，保留原始依据；历史调整通过审计留痕。

发布验收至少覆盖一个真实测试项目：业务申报到账→财务确认→工程回款进度→老板账本；工程采购→财务分次付款→退料结算；业务设计费垫付→分次报销→平台退款与员工归还；前期账本→建立工程→核对金额不重复。再按确认稿核对手机首页与Tab。
