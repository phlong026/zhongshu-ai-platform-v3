本轮发现及修复

问题修改前修改后验证方式
M01 凭证来源财务原入口仅能选择聊天文件，纸质凭证或手机截图要绕路。收款、付款、报销、退款及补充凭证统一提供拍照/相册和聊天文件；取消不清除已有凭证；选择失败显示可处理的提示。代码检查、选择器回调测试、真实PNG上传与财务登记
M02 异步回填选文件后返回、换单或切换身份，旧选择结果可能回填到后开的表单。校验会话、单据来源、表单代次和选择顺序；过期回调直接忽略，沿用已有登记接口。取消、换原单、换岗位与连续选文件回归通过
M03 PDF格式识别上传仅按临时路径后缀推断格式，无扩展名PDF会被当作JPEG。上传同时传递原文件名，以原文件名确定MIME；票据、字节上传、完成、原单关联及下载链路不变。真实PDF临时文件不带扩展名；下载返回application/pdf且字节以%PDF-开头
M04 键盘与底部导航财务固定底部导航未监听键盘，输入框未统一设置键盘间距。键盘弹起时隐藏底部导航，收起后恢复；39个输入框设置24px光标间距；返回账本主动收起键盘，页面隐藏/卸载释放监听。真实页面回调注入280/300px键盘事件及逻辑回归；未模拟系统键盘外观
