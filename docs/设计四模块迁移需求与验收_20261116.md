更新日期：2026-11-16。适用范围：众墅之家 AI 赋能平台 V3 小程序、B 后端、独立设计服务及公开案例源 A。

## 1 验收基准

业务基准为本机 `E:\众墅之家设计平台\zhongshu-home-design-miniprogram` 的前后端源码。前端原文件及摘要见 `design-parity-20261116/source-manifest.json`；后端对照及原算法摘要见同目录 `backend-source-manifest.json`。原项目作为只读参照。

业务一致指输入约束、默认值、参考选择、授权、状态转换、候选确认、结果版本、预算计算、缺项处理和历史恢复一致。B 登录、任职、公司积分和客户归档使用本项目已有实现。原 C 端充值、个人积分、投稿审核不作为 B 的业务入口。

迁移页面位于 `miniprogram/design-migration`，共 19 页。旧灵感库、平面、立面、预算、方案入口重定向到新分包，避免新旧业务并存。

### 2.1 图片完整性

列表和详情均按 `aspectFit` 显示，不裁切图片。详情保留各层平面及立面标签；分页不能在第一页停止，图片失败须提供重试。长页面中位于屏幕下方的内容通过滚动查看，点击图片可进入原生预览。

案例图下载必须携带 A 的案例与资产编号；公司生成结果图走设计服务资产下载，两类编号即使相同也不能混用。图片异步回写须保留完整案例、楼层及图纸身份，筛选切换后的旧回调不能覆盖新列表；原生回归同时检查图片加载后的记录编号与全部楼层图。

原图片经安全处理后，实际文件可能与最初上传文件具有不同摘要、大小及类型。A 导出的清单使用已入库对象的摘要和大小；GIF、BMP、TIFF 经原扫描器转为 PNG 时，清单相应声明 PNG。不能以原上传摘要校验安全处理后的对象。

### 2.2 原预算口径

迁移流程保留原输入白名单。占地可由面宽乘进深推导，建筑面积可由占地乘层数推导；实际面积不同须保留实际值及复核提示。屋顶面积及原本要求核定的工程量不会套用工作簿规则自动补齐。工程量覆盖按原整组替换处理。

原计算器的数量、金额、舍入和缺项算法原样保留，仅调整 Java 包名。迁移结果不增加 Excel 的 3% 管理费，也不输出该口径的报价汇总。完整与缺项预算均使用同一公司预算积分报价规则，缺项不等同于测算失败或免费。

## 3 B 身份、计费和客户适配

所有请求经 B 的 `/franchise/design/flow` 封闭资源路由；不从小程序直接访问 A 或持有 C 端用户令牌。B 验证登录、任职和设计角色，设计服务使用本公司的独立服务账号。原 C 用户账号和钱包不参与。

报价使用实际公司积分的 `ai_flat`、`ai_elevation`、`budget_estimate` 科目及价格版本。即使积分数值相同，价格版本变化也必须重新确认。公司未开通错误 `1072000001` 保持原意；价格变化单独使用 `1072000016`，前端映射为 `DESIGN_PRICE_CHANGED`。

退款展示取自本公司、本租户、对应命令的实际预占及结算账本。结算尚未完成时不显示“已退 0 积分”，也不按候选张数推测退款。命令、请求快照和幂等键在岗位、账号切换后隔离，迟到响应不得覆盖新会话。

历史任务未存出图规格时，按原查询规则回退为平面 2K 竖图、立面 2K 横图；已存规格优先。此规则与新建页面默认的 2 张、2K 横图分别适用。历史时间使用带时区的 ISO 时间，取消动作与原任务状态限制一致。

保存至客户先验证客户写权限，再读取公司拥有的冻结设计版本或预算版本。预算摘要读取原 `faceWidth`、`depth` 字段。缺项预算可以作为参考资料归档，保留空总额及完整缺项快照；公开手工预算接口的校验保持原规则。重复提交返回已保存方案，跨公司或无权客户不可写入。

## 4 跨服务案例协议

A 新增只读公开接口：

- `GET /app-api/design/v1/cases/public-generation-candidates`
- `GET /app-api/design/v1/cases/{id}/public-generation-candidate?caseVersionId=...`
- `GET /app-api/design/v1/cases/{id}/generation-reference?caseVersionId=...&line=FLAT|ELEVATION`

上述接口只导出已发布、已审核且拥有当前公开展示权及所需生成权的案例。原 C 候选接口仍保留原登录及受限账号检查。B 的内部候选路径通过固定白名单映射到新增公开路径，不转发用户令牌。

设计服务校验固定 HTTPS 来源、对象域名白名单、文件大小、类型和 SHA-256，不跟随重定向。只导入图片与结构化参数，不把 A 的案例 ID 当成本地案例 ID。镜像按公司、源案例及源版本隔离；相同文件重试复用已接受资产。

授权租约不超过 120 秒，且不能超过 A 实际有效授权期限。每次生成前重新验证 A；源案例下架、授权撤回、版本变化或同版本图纸身份变化均不能继续使用缓存生成。数据库事务内新授权以数据库事务时间生效，保证授权与案例发布能在同一事务完成。

部署约束（已按第 7 节落实）：小程序、B 后端、设计服务需配套发布，A 需具备本文件第 4 节的新控制器。A 补丁见 `design-parity-20261116/source-a-generation-reference.patch`。

设计服务配置 `DP_PUBLIC_CASE_SOURCE_BASE`（A 的 HTTPS 根域名）、`DP_PUBLIC_CASE_ASSET_HOSTS`、`DP_PUBLIC_CASE_SOURCE_TENANT_ID`；调用方授权增加 `FLOW_READ`、`FLOW_WRITE`、`FLOW_FLAT_JOB`、`FLOW_ELEVATION_JOB`、`FLOW_REVISION`、`FLOW_BUDGET`。保留原签名、收据、额度与厂商配置。

执行设计服务迁移 `V20261116.922__original_design_case_references.sql`。回退脚本只允许尚未导入任何参考的空表回退，不删除已有案例映射或资产身份。预算地区、选项和已发布价格必须与原环境同步，才能达到同数据计算结果一致；未配置时显示真实缺项，不填演示单价。
