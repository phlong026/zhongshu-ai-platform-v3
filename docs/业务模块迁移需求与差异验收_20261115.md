## 1 人物库

### 1.1 入口与对象

“内容创作 → 创作工具”中的“我的作品”改为“人物库”，路由为 `pages/studio/characters/index`。视频创作区右上角的“我的作品”、任务成片保存和发布登记仍归作品管理。

每个人物包含人物资料、数字分身和克隆声音三部分。人物资料用于文案二创；数字分身和声音用于口播生成。人物名称、分身名称和声音名称是显示信息，生成必须使用服务端认可的资源标识。

人物资料沿用现有 `fr_content_persona`，不另建重复身份库：人物名称64字、身份经历200字、主营业务500字、目标客户200字、引导行动500字、人物类型32字、内容方向100字、人物特色500字，支持启用与停用。

普通业务员读取、搜索和选用本公司人物；业务负责人、公司老板和平台所有者按现有 `franchise:content:persona` 权限维护。服务端权限和公司范围是最终依据，前端隐藏按钮不能代替鉴权。停用人物不再用于新创作，历史文案和视频保留原快照。

### 1.2 数字分身与克隆声音

| 能力 | 当前实现 |
|---|---|
| 数字分身 | 在人物名下上传MP4人物视频，调用数字人服务制作，名称最多20字 |
| 克隆声音 | 在人物名下上传MP3声音样本，默认普通话，调用声音克隆服务 |
| 素材限制 | 单文件≤50MB，复用B内容素材上传、完整性校验和下载票据；接口不能接受任意外部素材链接 |
| 授权 | 提交前明确确认本人素材或已获当事人授权，允许在本公司制作与使用；后端保存授权版本、确认人、确认时间和素材摘要 |
| 状态 | 提交确认中、制作中、已就绪、制作失败、结果待核实；刷新只查询，不自动重新制作 |
| 试听 | 声音有可用试听地址时可播放；地址不可用时明确提示，不用占位提示冒充试听 |
| 口播选用 | 选择人物，再选择该人物名下已就绪的分身和声音；前端传本地资源ID，由后端解析服务资源标识 |
| 公司隔离 | 其他公司资源不可查询或选用；分身与声音必须属于同一人物；停用人物、未就绪资源或未完成积分结算的资源不可生成口播 |

不提供五视图生成入口，也不把照片五视图、形象场景、声音和口播分身当成同一类资源。参考项目的口播分身/声音模块是本轮依据，五视图模块不再属于本轮需求。

新表 `fr_content_digital_clone` 保存制作事实、素材引用、授权版本、服务任务凭证、资源标识、幂等键、提交状态和积分操作引用。原有作品表不用于存储人物或声音。

### 1.3 积分与重试

新增 `avatar_clone`、`voice_clone` 两个按次计费科目。**不设置推测的制作价格**；平台必须发布有效价格，价格缺失时拒绝制作，不按0积分调用外部服务。页面读取制作报价，提交时后端按同一价格快照核对确认金额并预扣，价格变化须重新确认。

创建流程为：校验人物及授权 → 校验B素材类型和归属 → 原子保存制作意图与积分预扣 → 事务外提交服务。制作成功结算；明确未受理或明确失败退回预扣；提交结果未知保留预扣，不能自动退点、自动重投或显示已成功。

网络异常时，前端保存完整请求及幂等键；重试读取同一笔制作。重新打开人物页可恢复原请求。后台幂等范围为公司、办理用户和请求键；同键不同参数拒绝。制作状态已落库、积分结算中断时，再次刷新可幂等完成结算。

目前制作状态通过显式刷新查询。进程在提交阶段中断且未取得服务任务号时，保留待核实事实，需管理员对照服务回执处理；不提供绕过账簿的“强制成功”按钮。

### 1.4 接口

以下路径均由B `/admin-api` 提供，前端不持有数字人服务密钥。

| 接口 | 用途 |
|---|---|
| GET/POST/PUT `/franchise/content/personas` | 公司人物资料列表与维护，更新携带人物ID路径 |
| GET `/franchise/content/personas/{personaId}/clones` | 人物名下分身和声音 |
| GET `/franchise/content/clones/quote?kind=AVATAR或VOICE` | 可用性、制作积分和授权版本 |
| POST `/franchise/content/personas/{personaId}/clones` | 提交制作，带Idempotency-Key、素材ID、授权版本和已确认积分 |
| POST `/franchise/content/clones/{id}/refresh` | 查询制作状态并完成可恢复结算 |
| POST `/franchise/content/tasks` | 口播传 `avatarCloneId`、`voiceCloneId`、完整文案和标题；服务端拒绝仅传显示名称的数字人请求 |

## 2 链接提取与爆款二创

### 2.1 已定位的问题

原“公司未开通设计能力”来自公司积分池错误码 `1072000010`。链接解析与设计都使用公司积分账户，原通用错误文案错误地限定为设计。该错误在预扣路径表示未找到当前公司的积分账户，不能据此认定用户没有设计岗位权限。

本轮后端改为“公司尚未开通积分账户，请联系平台开通”；内容页兼容旧后端错误码，明确提示联系公司管理员或平台。保留正常准入：未开通、停用、余额不足和业务权限未授权分别处理，不自动创建余额、不赠送积分、不绕过后端校验。用户当前公司线上账户状态仍须在管理端核实。

### 2.2 提取流程

1. 从分享文字中提取实际HTTP(S)视频链接，立即锁定提交按钮。
2. 调用链接解析并轮询；结果已有原文时直接进入二创。
3. 只有音视频地址时继续调用语音转写，使用服务端解析出的地址与时长。
4. 保留原视频标题、来源链接和提取任务引用。空结果、失败、结果待核实分别提示，不生成演示文案。
5. 同一页面同链接重试复用同一组解析/转写幂等键。离页、换岗或切换账号后丢弃迟到结果。
6. 二创从人物库按准确ID选人，重名不混用；停用或被移除的人物须重新选择。自定义人设作为补充要求上送，不能只显示在页面里。

链接解析、转写、文案改写按各自计费科目处理。转写仅在没有现成文案且存在可用媒体时调用，不能对所有链接重复执行。
