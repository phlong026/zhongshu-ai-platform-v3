# 资料分类管理、后台名称及侧栏调整验收

2026-11-16 已部署到[正式管理后台](https://platform.zszhj.com/admin/training/materials)。

## 已完成

- 后台标志旁名称、浏览器标题、加载页和页脚统一为“管理后台”。
- 按用户确认的方案整理六组导航：工作台、组织与权限、课程培训、运营与积分、定价与套餐、系统与审计。“组织与权限”排第二。
- 侧栏展开宽度 220px，支持收起，展示最多两层；按已授权菜单重组，保留原页面地址，员工门户的菜单权限逻辑继续沿用原实现。
- “资料库 → 分类管理”支持新增、重命名、删除。默认六个业务分类均可修改；“未分类”为保留分类。
- 重命名同步更新该分类下的资料及其修订号。删除分类时，全部未删除资料自动归入“未分类”，文件及课程对具体版本的引用保持可用。
- 分类名称最多 40 个字符，校验空名称、重名及保留名称；操作仅限总部超级管理员，并记录审计。分类修改使用修订校验，删除前再次核对资料数量，防止旧确认窗口误处理新增资料。
