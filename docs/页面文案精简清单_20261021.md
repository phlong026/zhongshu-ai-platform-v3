# 页面文案精简清单（2026-10-21）

目的：整理商业化小程序里不应向用户展示或应大幅精简的文字，供后续统一删除。本清单只做盘点，**没有改动任何源码**。

## 一、口径与方法

- 扫描范围：`miniprogram/` 下全部 wxml 的静态文字、placeholder、title，以及 js 视图模型里的中文文案字符串。
- 分类按关键词与长度自动归类，再人工看过代表性页面截图，**条目需要在删除前逐条确认**，尤其是 js 里的字符串，有的是报错提示而不是常显文字。
- 受限：通过 js 拼出的动态文案（例如把数字拼进句子）没有被完整扫描到，实际遗漏会比这里多；真机上逐页看一遍后建议补充。

| 类别 | 含义 | 条数 | 处理 |
| --- | --- | --- | --- |
| A 演示/模拟标识 | "示例数据""本地演示""模拟"等 | 90 | 全部删除，演示逻辑一并移除 |
| B 未接入类提示 | "尚未接入""不会扣费"等开发口吻 | 7 | 改写为产品级状态，或隐藏入口 |
| C 内部规则说明 | 回避、复核、原单勾稽等治理规则 | 48 | 页面上删除，规则放二级说明页 |
| D 重复性提示 | 状态已可见的解释、长提示 | 62 | 精简或删除 |
| E 演示模块 | `pages/demo/` 与 demo 工具 | 108 | 整个演示模块不进入正式包 |
