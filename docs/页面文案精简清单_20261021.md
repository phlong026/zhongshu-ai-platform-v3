## 一、口径与方法

- 扫描范围：`miniprogram/` 下全部 wxml 的静态文字、placeholder、title，以及 js 视图模型里的中文文案字符串。
- 分类按关键词与长度自动归类，再人工看过代表性页面截图，**条目需要在删除前逐条确认**，尤其是 js 里的字符串，有的是报错提示而不是常显文字。
- 受限：通过 js 拼出的动态文案（例如把数字拼进句子）没有被完整扫描到，实际遗漏会比这里多；真机上逐页看一遍后建议补充。
