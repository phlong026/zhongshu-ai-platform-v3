## 小程序依赖决策

- `miniprogram-automator 0.13.0`：MIT，npm 协作者为 `wechat-miniprogram`，当前版本近期发布。审计所谓修复会降到多年以前的 `0.12.1`，既没有清晰证明可清除 Jimp 旧链，也可能破坏微信开发者工具自动化协议，因此拒绝盲降。
- `xlsx 0.18.5`：Apache-2.0，npm 公共仓库版本陈旧；SheetJS 官方文档明确称公共 npm registry 已过期，并推荐从其官方 CDN 安装 0.20.3。把依赖源改为厂商 tarball 是供应链策略变更，不应在上线前静默实施。建议另建任务：固定官方 0.20.3 tarball + SHA-512，核对许可证/制品镜像并对实际 Excel 导入做不可信输入回归。
- 线上门禁：当前 `npm audit --omit=dev` 为 0；自动化与表格工具只在隔离开发/CI 环境运行，不处理生产用户上传内容。若代码探索证明 `xlsx` 被打入线上包，则本结论必须升级为上线阻断项。
