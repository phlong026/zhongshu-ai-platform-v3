## 8. 风险提示与常见坑

1. **评审口径风险（最高）**：本仓库 `server/` 是 mock、`pages/admin/` 是小程序工作台，二者都不是「后端 / Web 管理后台」。把它们当生产组件评审会漏掉真正上线主体。
2. **测试假象风险**：144 个退役桩让 `npm run check` 恒绿。上线门禁应改为「真实生产后端联调报告 + 真机 UAT 报告」双签字，而非脚本退出码。
3. **域名风险**：`urlCheck:true` 只校验配置存在，不校验 COS 动态 `uploadUrl` / `downloadUrl` 域名。真机上传/下载附件失败是本次最可能出现的线上事故，建议优先做一次真机附件全链路实测。
4. **隐私合规风险**：微信小程序自 2023-09 起强制《用户隐私保护指引》，未配置会导致 `getPhoneNumber`、`chooseAvatar`、`chooseMedia` 等在真机被拦截。这类问题模拟器常常复现不了。
5. **包体风险**：主包未压缩约 1.86MB，图片几乎不压缩。若开发者工具实传超 2MB 才处理会打乱发布节奏，建议提前一次实传校验。
6. **双仓库版本漂移**：`admin-ui/dist` 已落后源码 4 天；两仓库 Git 历史独立，务必明确同一发布批次的前端版本、后端 commit、后台 dist 三者对应关系。
7. **资金操作风险**：付款撤销为 DELETE + 非粘性幂等键 + 前端硬编码权限，是本次新增的最高风险写操作。首发建议隐藏。
8. **法律文本风险**：协议正文占位、账号注销仅线下指引（无线上自助办理路径），属合规硬伤。文档已明确「agent 不得自行起草法律文本上线」（`docs/交接文档_待完成事项_20261022.md:175`），必须由业务方与法务定稿。
9. **文档漂移风险**：README 最新记录停在 10-29/10-30，仍大量使用「本地演示 / 服务端未接入」历史口径，与 CHANGELOG 的「纯 API 态切生产」冲突，易误导交接与后续评审。
