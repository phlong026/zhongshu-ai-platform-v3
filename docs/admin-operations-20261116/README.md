# 组织运营三项功能验收记录

验收日期：2026-11-16。三项功能已发布到现有 B 服务及管理后台，未替换其他会话的登录、设计业务实现。测试涉及的写入限定在本次独立测试组织与测试账号。

## 使用入口

- [组织管理](https://platform.zszhj.com/admin/platform-org/onboard)：已开通组织 → 详情 → 组织资料、能力开通、操作记录。
- [任务与积分核对](https://platform.zszhj.com/admin/platform-task-ops)：总部管理员查询跨组织任务；组织详情也有按当前组织打开的入口。

## 已补齐的行为

| 功能 | 本次交付 |
| --- | --- |
| 组织资料维护 | 修改组织名称、品牌、区域、地址、联系人、老板姓名和手机号；显示登录账号及微信绑定状态。老板更换是独立操作，从该组织有效成员中选择，保留原有登录账号，不转移个人密码或微信绑定。 |
| 组织能力开通 | 从统一定价目录读取 13 项能力，逐项启停并记录原因。未定价的数字人形象、语音克隆不能开通；新组织初始全部关闭。上线时为已有组织保留原有 11 项能力。 |
| 任务积分异常核对 | 区分生成状态、账务状态、核对状态；查看冻结用量、原预扣价格、积分流水和核对历史。支持跟进记录、已知终态同步、符合条件的不确定任务人工核验，核验结果决定结算或退回原预扣。 |

资料修改、老板更换、能力调整和任务核验均要求平台超级管理员，校验总部租户、组织范围、原因、版本及请求号。请求超时可恢复同一笔待确认操作；重复提交不重复记账，版本过期或同请求号不同内容返回冲突。

老板更换只调整目标组织的老板岗位，保留其他岗位及其他组织身份。手机号变更校验唯一性；涉及共享身份或超级管理员身份时阻止直接修改。实际改号会使该用户原有登录会话失效。

关闭能力拦截新预扣，已预扣任务仍可完成结算或退回。核验使用服务器保存的冻结用量和价格，不接受客户端自报积分。并发相反结论只有一方成功；账务写入失败时，任务状态、核对记录和审计一起回滚。

同时修正组织积分统计：预扣不计作消费，退回不计作消费；本月消费和累计消费仅取真实结算，在途预扣单独展示。月份沿用原任务的计费月份。
