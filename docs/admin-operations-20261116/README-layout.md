# 后台布局检查与调整

2026-11-16，已发布到管理后台。覆盖当前平台管理员实际可见的 22 个入口，包含工作台、定价管理、任务积分核对、总部运营八页、系统设置五页、运维支持五页和组织管理。

## 调整内容

- 共用表格按容器分配列宽，长组织名、账号、编号、时间、URL 和 JSON 自动换行；修正提示单元格遗留固定宽度造成的相邻字段重叠。
- 列数多或容器较窄时，同一条记录改为带字段名的分组展示，保留原表格中的操作、权限、勾选和控件事件，不通过隐藏列或截断文字消除横向滚动。
- 用户管理的部门树与主表按可用宽度上下排列，筛选项和操作按钮自动换行。
- 通用弹窗默认宽度由 40% 改为 720px，并受视口限制；窄屏弹窗使用接近全宽，多列表单改为单列，内容纵向滚动且底部按钮保留。
- 描述列表、长文本、JSON、目录树标签同步处理换行。

## 验证结果

22 个入口分别在 1366、1004 和 390 像素视口检查，共 66 次页面布局检查；页面宽度和实际可见表格均未测到横向溢出，已显示单元格未测到内容越界。

另检查组织详情六个标签、用户/角色/部门/配置/文件配置表单、能力调价、调价记录、充值套餐编辑、登录日志详情及有 15 条记录时的任务核对列表。已打开的表单未提交。窄屏实际勾选一行后再清除，批量按钮状态正确；登录日志翻至第 2 页再回第 1 页，分页正常。

没有数据的页面检查列头、筛选项和空态；不能以空表检查代替所有真实数据场景的验证。长字段验证使用现有用户、部门、日志、设计成本、配置审计和任务记录。未创建充值订单、未改价格或账号、未调用付费生成服务。

前端 51 项回归测试、Vue 类型检查和生产构建通过。本轮只发布前端，未重启或发布后端。
