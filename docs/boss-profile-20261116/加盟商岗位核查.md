# 加盟商各岗位“我的”页核查

按用户要求核查加盟商全部 8 个岗位，保留现有模块顺序，保留“学习培训”和“加盟商服务”。

| 岗位 | 可见课程及配套资料 | 我的页推荐课 |
| --- | --- | --- |
| 老板、门店负责人 | 全部 6 门岗位课程 | 门店经营与团队管理 |
| 业务员、业务负责人 | AI短视频获客实战、客户跟进与业务办理 | AI短视频获客实战 |
| 工程人员、工程负责人 | 乡墅开工与现场交底 | 乡墅开工与现场交底 |
| 财务专员、财务负责人 | 财务收支与项目对账 | 财务收支与项目对账 |

加盟商各岗位均显示“加盟商服务”中的“展陈设计”和“众墅甄选”。模块继续依次为：个人资料、公司积分、消息与任务、组织与工作身份及岗位入口、门店管理（老板/门店负责人）、学习培训、加盟商服务、帮助与隐私、退出登录。

本轮仅补齐门店负责人的全部岗位课程权限。共用的个人页模板与样式没有修改；老板仍开放全部课程，其他岗位维持按职责限定。课程中心、详情和学习资料使用同一目录，直接访问其他岗位的课程或资料同样受限，切换岗位后刷新当前权限。
