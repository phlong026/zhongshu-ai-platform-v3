## 已跑通流程

业务员提取预置链接 → 二创 → 数字人口播/AI任务 → 完成演示任务 → 保存作品 → 发布时选账号 → 提交当前版本审核 → 负责人首页岗位待办审核 → 原作者确认发布 → 发布回执登记咨询 → 负责人分配 → 业务员接受、跟进、转客户 → 客户列表出现新客户 → 关联该客户选案例及原户型检索 → AI平面候选选择、保存 → 预算测算、回存同一档案。

客户责任、组织/团队隔离、内容版本绑定、账号授权、正式设计独立审核、财务独立核算和工程移交沿用原规则。负责人不会因进入页面获得他人的账号发布授权；后续正式设计、收付款、施工与交付原链也已回归。
