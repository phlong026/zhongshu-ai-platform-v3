## 一、背景与目标

绩效提成经营（3.7-3.11）是 v3 管理模块的后端化：**月度目标（三级）→ 绩效任务（manual+10 类 auto 指标实时派生）→ 周期复核与申诉 → 回款提成（老板定规则/财务按净实收足额生成应付/人工核对）→ 经营视图（月末对账+快照归档+聚合分析）**。建模基准 = **任务机制**（performance-tasks.js 唯一基准；旧"周期档案自动派生"不建——owner-page 已封口旧目标页为只读佐证单轨方向，D-2）。组织管理 3.11 主体已交付（/platform/org/**，13f6a25），本批零改动（D-8）。
