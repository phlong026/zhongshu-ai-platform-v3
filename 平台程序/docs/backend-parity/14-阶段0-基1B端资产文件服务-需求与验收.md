## 一、背景与目标

阶段 2 工程（图纸/现场照片）与阶段 3 管理（财务凭证 UI）开工前，B 端需要一个**通用资产上传通道**（07 §七 出口验收：「工程模块开工前，图纸/照片上传在 e2e 里走通基-1 服务；财务凭证 UI 有可引用的上传通道」）。

现状盘点（勘察详 §二）：**资产票据制本体已存在**——design 模块 `AssetService`（签发→上传→complete 审核→下载签名）经板块 A 已被 B 端员工以组织服务账号身份用上（`/franchise/design/assets/**` 三端点，05 文档 R6/R7/R8）；finance 域另有自有 multipart 凭证通道（fr_fin_file）。基-1 的实质工作**不是重建能力，而是抽平台级通道**：

1. **类型字典泛化**：`AssetTypePolicy` 从现有 6 个 C 端类型扩入 B 端业务四类（财务凭证/工程图纸/现场照片/合同附件），零新表零迁移（D-基1-1/5）。
2. **免审分流 + 入口隔离**：B 端业务文件不做 C 端内容审核（D-基1-4），且**仅 B 端入口可达**（D-基1-4a）——外部审核服务可用性不得阻塞财务登记等关键操作，C 端用户不得借道免审上传。
3. **通用代理域**：新薄域 `franchise-asset`（`/franchise/assets/**`），不挂在语义为设计的 `/franchise/design` 路径下；各消费域经 `franchise-api` **新 Port `AssetAccessPort`** 引用 assetId（零新表，D-基1-1）。
4. **引用校验契约**：消费域引用 assetId 前经 Port `validateReference` 校验「存在 + ACCEPTED + 属主=本组织服务账号」（与 06 文档 D28 已交付的 `DesignServicePort.validateAsset` 同一校验实现，失败语义不同）。

## 四、REST 接口契约（`/admin-api/franchise/assets/**`）

断言口径：成功 `(HTTP 200, body.code=0)`；未认证 `(200,401)`；业务失败 `(200,业务码)`。全部要求 token+X-Post-Id（`currentPost.require()`；唯一任职缺 header 自动选中，F12）。

| 端点 | 请求 | 响应 | 说明 |
|---|---|---|---|
| POST `/franchise/assets/upload-tickets` | `{assetType, mimeType, sizeBytes, sha256}` | `{assetId, uploadUrl}` | assetType ∈ D-基1-5 四类（非法→1_071_000_001）；uploadUrl=COS PUT URL 或 `local://` 占位（F11，local 字节走 dev 端点落） |
| POST `/franchise/assets/{assetId}/complete` | — | `{assetId, uploadStatus, rejectedReason?}` | **B_END 免审直 ACCEPTED**（D-基1-4b）；终态重放幂等读；属主非本组织→`1_099_000_002` |
| POST `/franchise/assets/{assetId}/download-tickets` | — | `{downloadUrl, expiresAt}` | COS=签名 URL+到期；**local=`local://…?expires=` 占位（非 HTTP，不做 HTTP 断言），字节核验走 dev 读取端点**（F11/AC3） |

**审计**（F8 缺口的部分补齐，口径对齐板块 A 事务边界）：仅两个**写操作**记 CommandLog——`upload-tickets`（action=`fr-asset-upload-ticket`）与 `complete`（action=`fr-asset-complete`），在能力调用返回后以**独立短事务** `commands.record`（aggregateId=assetId，revision=雪花，payload 含 actorUserId/actorPostId/assetType）；**download 不记**（读/签名操作）。审计 record 失败将使请求失败、能力已生效；**重试语义两者不同**：`complete` 幂等重试无害（终态幂等读）；`upload-tickets` 无幂等键，重试=签发新票据+孤儿 PENDING 行（不可引用、无害但非幂等）。与板块 A 同款：不复用 replayed 收据（资产端点无收据语义）。
