## A2 必搬工程件（复刻项目已踩坑验证）

1. **提交即持久化 provider_task_id**：拿到供应商任务号后、开轮询前落库（超时/崩溃不丢已付费结果）。
2. **失败三分法**：明确拒绝（HTTP 400/401/402/403/404/422 白名单→直接终态失败不重试）/ 提交不确定（网络类→SUBMISSION_UNCERTAIN 状态，冻结计费，绝不自动付费重投，人工核验出路）/ 暂不可用（超时→继续等）。未知状态一律按 RUNNING 继续等。
3. **成片直链交付**：任务行只存供应商 result_url（HTTPS 校验），不即时下载转存；直链过期 HEAD 探测（403/404/410→已失效文案）。
4. **fake provider 通道**：开发联调/e2e 不触付费接口（env 控制结局 ok/failed/uncertain，结果可指向本地夹具）；生产硬禁（守卫常量）。
5. **Provider 适配五件套**（无框架、逐域自包含）：密钥只进服务端加密配置（不进代码/日志/PR）+ 外呼统一调用日志（provider/endpoint/耗时/结果码）+ 对外文案永不出现供应商名（中性中文+错误码）+ 可注入传输层（接口化便于 fake 测试）+ fake 通道。
6. **轮询参数**：H3 类查询 5s 间隔、任务最长轮询 2 小时超窗转人工；口播按秒预扣（秒数=字数÷2）。
7. **ASR 韧性**：已有 provider_task_id 免二次付费恢复轮询；同视频内容共享转写缓存（只付一次）。
