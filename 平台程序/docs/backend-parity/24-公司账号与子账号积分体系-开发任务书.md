## 一、目标与非目标

**目标（本任务书范围）**
1. org 积分池账户 + 三态计费流（RESERVE→SETTLE/RELEASE）+ 双主体流水（org 资金主体 / actor 消耗人）+ 任务合并视图——批 A 账本地基；
2. **科目价格目录**（价格来源/单位/取整/版本/快照结构——Codex R1-P1：现 Subject 无价格字段，内容域此前只做配额计数未扣费）；
3. 公司设计能力开通（org onboard 扩展）+ 公司池初始化；
4. 老板/员工/总部三层视图接口；
5. 员工月度额度（复刻项目同款：无行=不限、实时聚合、在途占用、跨月归原月）；
6. 员工业务权限矩阵（可选启用，无行=全允许）；
7. 激活码退役与存量迁移（最后批，前置=身份映射核实，见 §八）。

**非目标（登记不做）**
- 充值支付链（`ZS_RECHARGE_ENABLED=false` 首发不变，充值入池留接口不给实现）；
- 设计小程序登录链改造（→ §九 D5，**批 D 退役的前置**，不阻塞批 A-C）；
- 提现/分账/发票；跨组织共享池；个人池（D4 已拍板下线）。

## 三、表设计（commerce 段正向 `V20261113.311__*.sql`；undo 放独立目录 `db/migration-undo/commerce/V20261113.311__undo_*.sql`——**同版本号配对，不占 312 号**（R1-P2，对齐 310 现状与 07 号 §规矩）；续号前核对仓库已登记版本与目标库执行历史）

```sql
CREATE TABLE org_point_account (
  id           BIGINT PRIMARY KEY,
  org_id       BIGINT      NOT NULL UNIQUE,
  balance      BIGINT      NOT NULL DEFAULT 0 CHECK (balance >= 0),  -- 可用余额=SUM(delta)；在途预留=未终结 operation 另列展示
  status       TEXT        NOT NULL DEFAULT 'ACTIVE',  -- ACTIVE | SUSPENDED
  version      BIGINT      NOT NULL DEFAULT 0,         -- 乐观锁（余额 CAS；额度串行化靠行锁）
  create_time  TIMESTAMPTZ NOT NULL DEFAULT now(),
  update_time  TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE org_point_ledger (
  id                  BIGINT PRIMARY KEY,
  org_id              BIGINT      NOT NULL,
  operation_id        BIGINT,                 -- 计费周期贯穿 id；调点/迁移为 NULL
  biz_key             TEXT        NOT NULL UNIQUE,  -- 稳定业务幂等键（B-4）；调点=adjust:{key}；赠点=onboard-grant:{orgId}
  operation_time      TIMESTAMPTZ,            -- RESERVE 发起时点快照——三态行均复制，禁止终态重算（R1-P2）
  type                TEXT        NOT NULL,   -- RESERVE | SETTLE | RELEASE | MANUAL_ADJUST | MIGRATION
  subject             TEXT,                   -- 科目 key；调点为 NULL
  actor_user_id       BIGINT,                 -- 消耗人；调点=操作管理员
  actor_post_id       BIGINT,                 -- 消耗时在岗岗位
  available_delta     BIGINT      NOT NULL,   -- RESERVE=-N / SETTLE=+max(N-M,0) / RELEASE=+N / 调点=±X
  billing_month       TEXT,                   -- 上海自然月 'YYYY-MM'——三态行均写 RESERVE 发起月快照
  price_snapshot      JSONB,                  -- {subject,unit,pricePerUnit,priceVersion,quantity,M}——结算按此换算，禁重取现价
  ref_type            TEXT,                   -- content_task | ai_job | design_flat | design_elevation | budget_estimate | note_polish | ...
  ref_id              BIGINT,
  note                TEXT,
  create_time         TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_opl_org_time   ON org_point_ledger (org_id, create_time);
CREATE INDEX idx_opl_actor      ON org_point_ledger (org_id, actor_user_id, billing_month);
CREATE UNIQUE INDEX uk_opl_reserve  ON org_point_ledger (operation_id) WHERE type = 'RESERVE'   AND operation_id IS NOT NULL;
CREATE UNIQUE INDEX uk_opl_terminal ON org_point_ledger (operation_id) WHERE type IN ('SETTLE','RELEASE') AND operation_id IS NOT NULL;  -- B-5 终态互斥

CREATE TABLE org_member_quota (
  id               BIGINT PRIMARY KEY,
  org_id           BIGINT      NOT NULL,
  user_id          BIGINT      NOT NULL,
  monthly_credits  BIGINT      NOT NULL CHECK (monthly_credits > 0 AND monthly_credits <= 1000000000),
  create_time      TIMESTAMPTZ NOT NULL DEFAULT now(),
  update_time      TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (org_id, user_id)                 -- 删行=不限（唯一"不限"表达）
);

CREATE TABLE org_member_permission (
  id                BIGINT PRIMARY KEY,
  org_id            BIGINT      NOT NULL,
  user_id           BIGINT      NOT NULL,
  allowed_subjects  TEXT        NOT NULL,    -- 允许科目 key 数组 TEXT-JSON（排序去重；空数组=全禁）
  create_time       TIMESTAMPTZ NOT NULL DEFAULT now(),
  update_time       TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (org_id, user_id)                 -- 删行=全允许（fail-open，存量零回填）
);
```

**口径约定（R1 修订）**
- **可用余额** = `SUM(available_delta)`（单列制；**登记偏离**：复刻项目 available/pending 双列+提现语义，我们无提现，单列+未终结 operation 汇总展示在途——R1 评审认可可接受但需按本文口径查询）；在途预留 = 未终结（无终态行）operation 的 -RESERVE delta 汇总；
- 员工当月占用 = `-SUM(available_delta WHERE type IN ('RESERVE','SETTLE','RELEASE') AND org_id=? AND actor_user_id=? AND billing_month=当月)`（**三态全参与**：SETTLE 正退差与 RELEASE 全退均冲减占用——R1-P1 核心修正；占用口径代数上恒等于"当月实际消耗+在途"）；
- 表不带 `deleted` 列：**流水永不物理删除；配置表（quota/permission）删除行=语义"不限/全允许"，删除动作另记审计**（R1-P2：原文"永不物理删除"与删行语义矛盾，已拆分表述）；
- 多科目任务：按科目拆多个 operation（各自独立三态+独立 biz_key），合并视图按业务任务 ref 聚合展示。

`reserve(bizKey, orgId, actorUser, actorPost, subject, quantity, refType, refId) → operationId`——**服务端按 BillingPriceCatalog 快照换算 N，不信任调用方积分数**；`settle(operationId, actualQuantity)`——按原快照算 M；`release(operationId)`。
