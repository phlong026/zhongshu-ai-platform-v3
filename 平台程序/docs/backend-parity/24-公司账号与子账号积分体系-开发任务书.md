## 一、目标与非目标

**目标（本任务书范围）**
1. org 积分池账户 + 三态计费流（RESERVE→SETTLE/RELEASE）+ 双主体流水（org 资金主体 / actor 消耗人）+ 任务合并视图——批 A 账本地基；
2. 公司设计能力开通（org onboard 扩展）+ 公司池初始化；
3. 老板/员工/总部三层视图接口（余额、全员用量、个人用量、池流水双视图）；
4. 员工月度额度（复刻项目 `sub_account_quotas` 同款：无行=不限、实时聚合、在途占用、跨月归原月）；
5. 员工业务权限矩阵（可选启用，无行=全允许）；
6. 激活码退役与存量迁移（最后批）。

**非目标（登记不做）**
- 充值支付链（`ZS_RECHARGE_ENABLED=false` 首发不变，充值入池留接口不给实现）；
- 设计小程序登录链改造（→ §九 D5 待拍板，不阻塞批 A-C）；
- 提现/分账/发票（复刻项目也无）；跨组织共享池；个人池（D4 已拍板下线）。

| # | 批 | 任务 | 要点 | 验收 |
|---|---|---|---|---|

## 三、表设计（commerce 段迁移 V20261113.311，成对 undo 312；实施时按同 location 已执行最大版本续号）

```sql
CREATE TABLE org_point_account (
  id           BIGINT PRIMARY KEY,
  org_id       BIGINT      NOT NULL UNIQUE,
  balance      BIGINT      NOT NULL DEFAULT 0 CHECK (balance >= 0),
  status       TEXT        NOT NULL DEFAULT 'ACTIVE',  -- ACTIVE | SUSPENDED
  version      BIGINT      NOT NULL DEFAULT 0,         -- 乐观锁（余额变更 CAS）
  create_time  TIMESTAMPTZ NOT NULL DEFAULT now(),
  update_time  TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE org_point_ledger (
  id                  BIGINT PRIMARY KEY,
  org_id              BIGINT      NOT NULL,
  operation_id        BIGINT,                 -- 计费周期贯穿 id（任务级）；调点/迁移为 NULL
  operation_time      TIMESTAMPTZ,            -- operation 发起时点快照（额度月归属锚）
  type                TEXT        NOT NULL,   -- RESERVE | SETTLE | RELEASE | MANUAL_ADJUST | MIGRATION
  subject             TEXT,                   -- 科目 key（ContentBillingCatalog / 设计域科目）；调点为 NULL
  actor_user_id       BIGINT,                 -- 消耗人；调点=操作管理员 user_id
  actor_post_id       BIGINT,                 -- 消耗时在岗岗位（审计）
  available_delta     BIGINT      NOT NULL,   -- RESERVE=-N / SETTLE=+max(N-M,0) / RELEASE=+N / 调点=±X
  billing_month       TEXT,                   -- 上海自然月 'YYYY-MM'（RESERVE/SETTLE 行写快照；占用聚合键）
  price_snapshot      JSONB,                  -- 快照冻价（四原则①）
  ref_type            TEXT,                   -- content_task | ai_job | design_job | budget_estimate | ...
  ref_id              BIGINT,
  note                TEXT,
  create_time         TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_opl_org_time   ON org_point_ledger (org_id, create_time);
CREATE INDEX idx_opl_actor      ON org_point_ledger (org_id, actor_user_id, billing_month);
CREATE UNIQUE INDEX uk_opl_reserve ON org_point_ledger (operation_id) WHERE type = 'RESERVE' AND operation_id IS NOT NULL;

CREATE TABLE org_member_quota (
  id               BIGINT PRIMARY KEY,
  org_id           BIGINT      NOT NULL,
  user_id          BIGINT      NOT NULL,
  monthly_credits  BIGINT      NOT NULL CHECK (monthly_credits > 0 AND monthly_credits <= 1000000000),
  create_time      TIMESTAMPTZ NOT NULL DEFAULT now(),
  update_time      TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (org_id, user_id)                 -- 删行=不限（唯一"不限"表达，对齐 16a 无行语义）
);

CREATE TABLE org_member_permission (
  id                BIGINT PRIMARY KEY,
  org_id            BIGINT      NOT NULL,
  user_id           BIGINT      NOT NULL,
  allowed_subjects  TEXT        NOT NULL,    -- 允许科目 key 数组 TEXT-JSON（排序去重；空数组=全禁）
  create_time       TIMESTAMPTZ NOT NULL DEFAULT now(),
  update_time       TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (org_id, user_id)                 -- 删行=全允许（fail-open，存量零回填）
);
```

**口径约定（对齐 16a）**
- 余额 = `SUM(available_delta)`（单列制；**登记偏离**：复刻项目为 available/pending 双列+提现语义，我们无提现，单列足够——评审重点挑战项）；
- 员工当月占用 = `-SUM(available_delta WHERE type IN ('RESERVE','SETTLE') AND billing_month = 当月 AND actor_user_id = ?)`（SETTLE 正 delta 退差自然冲减；RELEASE 不参与=已释放）；
- 表不带 `deleted` 列（流水/额度/权限永不物理删除，审计红线）——与 franchise 域惯例一致，实施时对照 commerce 既有表风格；
- 多科目任务（如一次生成含解析+改写）：**按科目拆多个 operation**，各自独立三态（合并视图按业务任务 ref_id 聚合展示）。

## 四、接口设计

| 端点 | 方法 | 说明 | 权限 |
|---|---|---|---|
| `/platform/org/onboard` | POST | **扩展**：+`designEnabled`/`initialCredits` | `platform:org:onboard`（既有） |
| `/platform/org-point/summary` | GET | 余额+当月全员用量排行 | 老板/owner（pf 岗位权限） |
| `/platform/org-point/operations` | GET | 任务合并视图（分页，服务端折叠） | 老板/owner |
| `/platform/org-point/ledger` | GET | 逐笔流水（分页；支持 actor/subject/月筛选） | 老板/owner |
| `/platform/org-point/my-usage` | GET | 本人当月占用+明细 | 全部在岗员工 |
| `/platform/org-point/member-quotas` | GET/PUT | 额度清单/设置（PUT 幂等，删行=不限） | 老板/owner |
| `/platform/org-point/member-permissions` | GET/PUT | 权限矩阵清单/设置（同上语义） | 老板/owner |
| `/admin-api/design/v1/org-point-adjustments` | POST | 总部调点（Idempotency-Key 幂等） | yudao 权限码 `commerce:org-point:adjust`（新种子） |
| `/admin-api/design/v1/org-point-accounts` | GET | 总部跨公司池查询 | `commerce:org-point:query`（新种子） |

内部 SPI（franchise-api 端口合同，供各消费域调用，**绝不暴露 HTTP**）：
`OrgPointPort.reserve(orgId, actorUser, actorPost, subject, N, refType, refId) → operationId`；`settle(operationId, M)`；`release(operationId)`。实现强制顺序：**额度校验→余额 CAS→写 RESERVE 行→（事务外）外呼**；四原则④悬空预留对账 = 定时 Job 扫 PENDING 超 24h 的 operation 告警（复用 infra outbox/job 体系）。
