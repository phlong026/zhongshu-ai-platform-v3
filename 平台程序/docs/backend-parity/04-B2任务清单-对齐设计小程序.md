## 二、B2 任务清单

### 关键架构认知（澄清后）

设计小程序是 **B 端员工的工具**，连接到已有的 yudao-module-design/commerce/ai-orchestration 后端（`/app-api/design/v1/*`）。B2 不重建这些能力，只建一个**员工端接入层**（franchise-design），让 sales/hq-design-admin 通过 admin-api 使用。

**design_project.user_id 处理**：B 端员工创建时填**门店服务账号**（store setup 时自动创建一个 account，仅满足 NOT NULL 约束）；真正的归属通过 fr_customer_scheme（有客户时）或代理层审计日志（无客户时）追踪。
