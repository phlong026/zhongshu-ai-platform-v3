## 三、关键实现决策（供评审挑战）

1. **端口位置**：`OrgPointPort` 置于 `franchise-api`（纯合同模块），实现放 commerce（`OrgPointService implements OrgPointPort`）。代价：commerce → franchise-api 依赖一条（不依赖任何 franchise 业务模块），换取消费域零 pom 改动。
2. **余额口径**：单 `available_delta` 列，`balance=SUM(delta)`；在途=`inFlight(orgId)`（未终结 RESERVE 汇总），不落余额列。与复刻项目 available/pending 双列登记的偏离已获 R1 认可。
3. **原价快照换算**：RESERVE 快照存 `{subject,unit,priceMicrosPerUnit,priceVersion,minCharge,quantity,credits}`；SETTLE 用 `quantity/priceMicrosPerUnit` 重算 M（整数向上取整），不读目录现价。
4. **额外错误码**：`1_072_000_014 ORG_POINT_REPLAY_CONFLICT`（任务书 010~013 未覆盖"参数变化拒绝"场景，本批新增，需评审确认命名与段位）。
5. **content 幂等键**：`content:{taskId}:{subject}`，taskId 为创建前预生成的雪花 id；上线前存量任务无 RESERVE 行 → `settleByBizKey/releaseByBizKey` 静默 no-op（不补扣、不报错）。
6. **UNCERTAIN**：`settlePool` 对 `SUBMISSION_UNCERTAIN` 不做任何动作（保持 PENDING），人工核对端点按 D7 留到批 B/后续；本批不含自动退款。
