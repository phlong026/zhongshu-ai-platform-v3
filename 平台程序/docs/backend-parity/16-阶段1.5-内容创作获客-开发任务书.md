## 一、背景与目标

内容创作获客（1.13-1.16）是 v3 四个独立页面（creation/studio/ai-video/growth）的后端化：当前四页全部跑本地 Storage，生成能力为「服务暂未开通」的 demo 兜底。本批建 **franchise-content 域（fr_content_\*）**，把「口播文案 AI 优化 → 生成任务 → 作品 → 发布记录 → 客资转化」链路后端化，并让素材引用走基-1 资产通道。

**对标基准**：爆款系统是一套已验证的内容创作工作台（Go 单机版，约 14k 行，60 个 API 端点），其「文案引擎三层兜底」「生成产物可审计（model/prompt/来源链落库）」「异步任务模式」「人设注入」四项实现方案为本批直接对标对象；其「单机微信采集/本机授权/灰产对抗策略」**明确不搬**（§十）。
