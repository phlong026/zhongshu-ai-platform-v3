## 二、关键设计决策

1. **platform 不反向依赖业务模块**：onboard 扩展通过 `platform-org` 的 `OrgOnboardedEvent` 解耦；commerce 以 `@EventListener` 同步监听（同事务，池写入失败回滚开通，避免"组织已建但无池"）。
2. **视图控制器放 franchise-org**：它已依赖 `platform-authz`（`CurrentPost`）与 `franchise-api`（`OrgPointPort`），无需新增模块依赖；对应任务书 URL 前缀 `/platform/org-point/*`。
3. **权限**：老板视图以 `FranchiseRoles.isBoss`（boss/owner）门禁；未新增 `franchise:org:*` 岗位权限码（避免与既有种子冲突），平台侧调点/查询走 yudao 权限码 9570/9571。
4. **操作合并视图**在 SQL 层 `LEFT JOIN` 折叠后再分页（R1 教训：折叠必须在分页之前）。
