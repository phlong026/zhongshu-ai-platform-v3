# 业务模块迁移补充需求

2026年11月15日。补充16号内容创作任务书、05号设计赋能接入层需求。原任务书中的已实现描述不能替代本次与源设计小程序的逐项核对。

## 用户确认的范围

创作工具“我的作品”入口改为“人物库”；作品列表仍用于成片保存和发布。人物库需要人物资料、数字分身和克隆声音，不需要上传照片生成五视图。人物资料复用 `fr_content_persona`，分身/声音制作事实落新表 `fr_content_digital_clone`。

普通业务岗位读取和选用公司人物，业务负责人、公司老板和平台所有者按 `franchise:content:persona` 维护和制作。分身使用已校验的B内容MP4视频，克隆声音使用已校验的B内容MP3样本；单素材不超过50MB，素材授权、摘要和确认人持久化。

## 新增接口与执行规则

- `GET /franchise/content/personas/{personaId}/clones`：公司人物名下的制作资源及状态，不暴露服务资源凭证。
- `GET /franchise/content/clones/quote?kind=AVATAR或VOICE`：制作可用性、积分和授权版本。
- `POST /franchise/content/personas/{personaId}/clones`：人物、类型、名称、B素材ID、授权版本、确认积分，必须带幂等键。
- `POST /franchise/content/clones/{id}/refresh`：按任务凭证查询，禁止重新创建制作任务。
- 口播任务必须提交 `avatarCloneId` 和 `voiceCloneId`。服务端校验同公司、同人物、启用、就绪和积分已结算后解析实际分身与声音标识。旧任务幂等回读仍保留，新的口播创建不再接受显示名称代替资源ID。

价格科目为 `avatar_clone` 与 `voice_clone`，按次计量。无代码默认价格，平台发布有效价格后才能制作；缺价不按0积分外呼。`OrgPointPort.reserveConfirmed` 使用预扣采用的同一快照核对确认积分，价格已变或撤下时拒绝。

制作意图和公司积分预扣在同一事务提交，外部提交在事务外。明确失败释放，成功结算，提交结果未知保留预扣且禁止自动重投。相同公司、办理用户和幂等键只产生一笔制作；同键参数不同拒绝。前端持久化未确认请求，以同键续读。

状态为SUBMITTING、RUNNING、READY、FAILED、UNKNOWN；积分事实为PENDING、SETTLED、RELEASED。状态刷新使用短租约，终态积分收尾可幂等恢复。没有服务任务号的中断提交保留待核实，由运营对照服务回执处理，不提供强制成功或强制退点接口。

需执行 `V20261115.917__fr_content_digital_clones.sql`。对应undo仅允许删除无制作记录且无未终结积分预扣的空表，不能删除既有授权、制作或资金事实。本地开发不代表已经部署，不能直接让新小程序调用旧后端。

## 设计迁移仍须完成的范围

源设计前端的 `pages/library`、`pages/ai-design`、`pages/budget/quick`、`utils/design-inputs`、`utils/budget-draft` 与当前B小程序及 `DesignServicePort` 仍有实质差异：

1. 公司/AI来源筛选尚未透传；公开案例服务会移除DESIGN_WITH，未完成案例参考授权与资产映射，前端必须尊重白名单。
2. 平面缺带版本的参考候选/确认、草图和完整结果确认，创建契约缺refCaseVersionId。
3. 立面源流程允许只给层数和描述，B前端仍强制尺寸及高级选项；不能用默认值宣称规则已经相同。
4. 生成请求持久化续传、取消和部分成功的真实退款字段仍需对齐。
5. 原快速预算采用独立草稿、地区配置、分项工程量与单价、缺项提示、本人项目参数导入及历史报价；B当前仍采用绑定项目的面积区间预算，不能认定完整迁移。

完整验收必须使用同案例、同输入、同价格版本逐项比较，覆盖需求快照、允许动作、结果、逐项金额及总额，同时验证B身份、公司积分和客户归档。未关闭上述项前，不标记“完全一致”。
