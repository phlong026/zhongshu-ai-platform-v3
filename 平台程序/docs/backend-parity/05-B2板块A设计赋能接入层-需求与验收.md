## 一、背景与目标

设计小程序（zhongshu-home-design-miniprogram）已与 yudao-module-design/commerce/ai-orchestration 后端完整对接（`/app-api/design/v1/*`，17 页：灵感库/AI 设计两阶段管线/快速预算/点数充值）。**B2 板块 A 不重建任何 AI/预算/案例能力**，只建员工端接入层 `franchise-design`（独立薄域），让 sales/sales-lead/hq-design-admin 经 `/admin-api` 使用既有 C 端设计能力，并把 AI 结果回写 B 端客户档案（fr_customer_scheme）。

目标拆解：
1. **代理**：灵感库/资产上传/AI 设计两阶段管线/快速预算，员工经 admin-api 令牌调用，底层身份=本组织服务账号（identity account）。
2. **回写**：平面选定→PLAN、立面选定→FACADE、快速预算→BUDGET，写入 fr_customer_scheme（新增 design_project_id 关联列）。
3. **桥接**：设计项目 ↔ fr_customer 关联查询；结果资产可被员工端取图。
4. **底座**：双 Port（franchise-api）、门店服务账号惰性创建、853 权限种子、代理层审计留痕、e2e。

### 3.2 服务账号口径（A9 细化）

- **每组织（org）一个服务账号**（门店与总部都建，覆盖 hq-design-admin 总部场景）。
- **单层幂等（ON CONFLICT 语义，R6 评审后删除绑定表）**：
  1. identity：`AccountProvisionPort.ensureActiveAccount(externalKey, nickname)`，externalKey=`fr-service:{orgId}`；account.external_key 加**普通 UNIQUE 约束**（PG 唯一约束允许多个 NULL，与 `ON CONFLICT (external_key)` 推断匹配；仓库先例 AccessCodeRedemptionService）：`INSERT ... ON CONFLICT (external_key) DO NOTHING` 后**同事务 SELECT**；禁止「先 INSERT 捕获唯一异常再重查」模式。identity 为账号唯一写方。
  2. 解析路径唯一：`StoreServiceAccountPort.ensureForOrg(orgId)`（franchise-org）→ `AccountProvisionPort.ensureActiveAccount("fr-service:{orgId}", nickname)` → **每次都经 identity 校验状态（停用账号在查询与写入口径统一 1_112_000_004）**；不再维护第二份绑定映射。
- **状态边界**：任一路径（新建命中/绑定命中）解析出的账号 status≠ACTIVE（被管理端停用）→ 1_112_000_004 SERVICE_ACCOUNT_INACTIVE；**禁止惰性复活或换建新号**。identity 现无启用接口——**停用后本批无恢复路径，恢复能力=M5 待建（D23）**。
- 服务账号是**纯技术占位**：仅满足 design_project.user_id NOT NULL 与资产归属；B 端操作者身份以 Actor 随命令传递并落审计；回写行 author_user_id=post.userId()=system_users.id。
- **如实标注**：服务账号会出现在 identity 管理端账号列表/统计（昵称=`{组织名}·服务账号`）；**数据库层可凭 external_key 辨识；管理端响应为显式选列，暂凭昵称辨识**（管理端字段扩展另行立项，D22）。

## 五、回写契约（save-to-customer，R21）

| 项 | 规则 |
|---|---|

## 六、点数与计价口径

1. **扣点主体=服务账号**；点数不足 → design 原码透传，文案「设计点数不足，请联系总部充值」。
2. **本批不建充值链路**：dev-setup 注入（P-7）支撑 e2e 与演示；生产充值运营记 D14（M5）。
3. **取价内聚与重放边界闭合（R12/R13/R18/R20 一步完成）**：**能力方新增自动确认入口——先锁定并核验收据，仅首次执行才报价并构造 confirmation**（图片任务报价+AI_PROMPT usage 确认+预算 usage 确认三类）；**适配器不得先行报价**（否则报价规则停用/失效会阻断既有成功请求的重放，P-2⑧）。**扣费时点（F4）**：创建时确认并预扣 → Runtime 成功提示词调用独立 AI_PROMPT_DEBIT → 终态结算差额退点；规则在确认与提交间变更 → 原码透传（PRICE_RULE_CHANGED）重试。
4. **不代理**：钱包/充值订单/消息中心/投稿发布。
