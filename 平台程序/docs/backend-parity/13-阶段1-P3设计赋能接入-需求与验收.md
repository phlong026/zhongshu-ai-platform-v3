## §四、AI 轮询协议（S1-2 定稿）

- **间隔 3s、上限 90s**（30 次轮询）；轮询链挂 loadGen/sessionGen/postKey——任何变化立即终止轮询并丢弃响应。
- status 终态：SUCCEEDED/**PARTIALLY_SUCCEEDED** → 拉 R11 候选（部分成功且 acceptedCount=0 → 按 FAILED 文案）；FAILED → 文案「生成失败，请重试或调整参数」（原码透传）。
- **90s 超时（S1-2）**：提示「生成仍在进行，可稍后手动刷新」+ 手动刷新按钮（重进 R11/R14 单次）；**手动刷新命中未终态 → P-10 业务码 → 文案「仍在生成，请稍后再试」**（不直出原始码），**不自动终止后端任务**。
- **验收时钟注入点**：页面轮询经全局 setTimeout/setInterval——verify 脚本以 fake clock（替换全局定时器+手动 tick）驱动，禁止断言内真实 sleep 轮询。
- 轮询期间重复点击生成按钮 → busy 锁忽略；页面卸载终止定时器。
