## 一、背景与目标

工程全周期（2.1-2.9）是 v3 工程模块（pages/build/* + utils/engineering-*）的后端化：把「移交接收建档 → 开工准备（收款约定即生效）→ 施工计划 → 材料计划/采购/到货 → 现场记录 → 两期收款 → 交付→结算→归档」链路后端化。**建模唯一基准 = 蓝本 recordFlow 新链**（2026-10-28 四批次修订拍板后的目标形态：收款约定即生效、材料金额收窄、验收线下留痕、尾段三段化）；经典链不建（D-2），但其**已验证的机制**（顺移改期算法/质检与补发/材料去向）作为设计资产吸收进后端模型（标注于 F5/F6/F9）。
