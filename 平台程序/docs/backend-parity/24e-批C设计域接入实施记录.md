## 二、关键语义

- **绑定持久化**（D6 §2.1）：`org_id/actor_user_id/actor_post_id/operation_id/biz_key` 落 `design_billing_binding`；异步结算与恢复按绑定行判定，不依赖入口参数。
- **零写旧表**：桥侧任务不写 `ai_task_charge`、不写个人流水、不 prepare prompt 计费（`prompt_pricing_version=0`）。
- **终态映射**（D6 §2.3-A）：`billable=min(ACCEPTED, requested)`；`billable=0 → release`；`1..N → settle(billable)`（退差自动）；`ACCEPTED=N`（含取消但全有效）→ 全额结算。
- **禁双链**：`charge_id IS NULL` 是公司池任务唯一标志；缺绑定直接抛错（不允许静默走个人池）。
