# 参考图跨应用读取协议与验收边界

本次只修改独立 B 与小程序源码。共享 A 的代码、配置、数据库、JAR 和运行服务均未修改。真实独立 B、独立设计能力服务及 COS 的联调继续待部署；下述“通过”仅指本地源码、行为测试及 PostgreSQL 回归。

## 字节和编号如何传递

1. 小程序把最多三张 `referenceAssetIds` 放到创建立面项目的 `requirementInputs`。任务请求不再携带可变参考图；B 对旧任务级非空引用明确报错，避免忽略图片后收费。自传立面及案例参考立面均可带图片，平面和带草图的组合拒绝。
2. B 通过内部 `AssetAccessPort.readDesignReference` 读取自身存储，不发放免登录的 HTTP 下载通道。当前员工、任职、组织、租户及服务账号都要匹配，资产必须未删除、类型为 `DESIGN_REFERENCE`、状态为 `ACCEPTED`。读取的是扫描消毒后的不可变对象，重新核对其 `accepted_size_bytes/accepted_sha256`，不是原始客户端声明的摘要。
3. B 复用既有签名设计能力接口 `CREATE_UPLOAD_TICKET`，声明 `DESIGN_REFERENCE`、JPG/PNG、实际字节大小及 SHA-256。签名应用、组织和操作者使用已有服务端上下文，客户端不能指定远端账号。该步骤不创建生成任务、不预留积分。
4. B 向票据的 HTTPS 对象存储 URL 原始 PUT 字节，只带 Content-Type，不发送 B 的 Bearer、岗位、租户或服务签名。上传主机必须属于部署配置的精确白名单；拒绝跳转、用户信息、片段、非443端口及本地/dev代理地址。连接5秒、整个传输30秒期限；超时取消。
5. B 调用已有 `COMPLETE_UPLOAD`，必须得到对应远端 assetId 的 `ACCEPTED` 才写入持久化映射。待审核、拒绝、响应不匹配或上传失败均不创建项目或付费任务。远端重新执行自己的摘要、扫描与审核，B 的审核结果不能代替能力方的审核。
6. 将创建项目的引用替换为映射后的远端编号，再沿用原项目、任务和积分协议。B 编号不直接交给远端查库；远端仅读取自身资产。项目内的需求和参考图由能力方已有快照冻结，供任务运行时读取。

输入和输出编号空间必须分开：B 上传素材的下载使用 `/admin-api/franchise/assets/{id}/download-tickets`；设计候选、结果及能力侧图片使用 `/admin-api/franchise/design/assets/{id}/download-tickets`，远程模式固定走 `CREATE_DOWNLOAD_URL`，即使两边数字 ID 相同也不做“本地找不到再试远端”的回退。公开案例图使用独立B路由 `POST /admin-api/franchise/design/cases/{caseId}/assets/{assetId}/download-tickets`，先确认图片属于当前已发布案例，再调用A现有匿名下载票据及消费接口；不携带员工或服务Authorization，公开授权撤回时拒绝。前端逐张换票，避免四层平面加封面的五张图触发组织并发上限。图片票据失败或缺 URL 会进入页面已有错误处理，不以空串或“仍在生成”伪装失败。

## 重试、并发与资源限制

`fr_design_reference_mirror` 以 callerAppId、tenant、org、user、post、B资产ID及已审核字节SHA为主键。成功映射在进程重启后复用，但每次仍先校验原图读取权限。换租户、岗位、员工、组织或图片内容不能复用旧映射。

每个同步尝试保存独立 attempt_key，申请/完成的业务键固定为 `reference:<attempt>:ticket/complete`，由原远端命令收据机制提供幂等。未知结果不更换键；重试先对原票据做完成核验，已经收到的字节无需再次上传。仅远端明确 `REJECTED` 才分配新尝试；`PENDING/UNKNOWN` 保留原尝试。过期票据且未收到字节时，由远端明确拒绝后重新申请。

短事务领取10分钟租约；网络操作在事务外进行，步骤间续租并核对 fencing token。并发请求返回429；过期工作者不能覆盖映射或释放新工作者租约。全局最多4个、每组织最多1个读取/同步过程，控制三张20MB图片的驻留内存；忙时快速失败，不排队占用线程。小程序在项目或任务结果未知时保留两阶段业务键；更改参考图/案例后重置键和项目状态。

## 独立 B 配置与回滚

在独立 B 的外置 `platform.properties` 设置 `zhongshu.design.remote.reference-upload-hosts`，值为远端 COS 签名上传地址实际使用的完整小写主机，多个用逗号分隔。例如占位值 `bucket.cos.region.myqcloud.com` 必须替换为实际主机，不能配置通配符或完整 URL。也提供 `PF_DESIGN_REFERENCE_UPLOAD_HOSTS` launcher 别名；Compose 未转发该变量时须用外置属性文件。缺省为空，只有参考图同步明确拒绝，普通无图设计路径保持可用。服务签名密钥沿用既有外置配置，不新增密钥，也不记录签名URL。

增量迁移 `V20261115.970__reference_asset_mirror.sql` 只属于 B 的 `franchise-design-remote` location，ownership manifest 已登记正向与 undo 摘要。空表可执行 undo；存在任何映射时主动拒绝。停用功能并回退代码前必须保留 B 原图、映射和远端项目引用；不能删映射后重新创建一组不同编号来恢复既有幂等命令。远端已创建但未被项目使用的拷贝可能是孤儿，应按能力方既有保留/清理政策单独盘点，不能用自动删除触碰 A 历史资产。
