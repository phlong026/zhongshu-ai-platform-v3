- A `platform_cost_business` / `platform_cost_ledger`：SERVICE_COST、MICRO_CNY、累计 reserved/charged/refunded/units 符合规则；账本 event_key 不重复，version 单调。预算每次 usage=1，平面 prompt=1/image=1。

- B `fr_design_billing` / `pf_wallet_charge` / `pf_point_ledger`：每命令一份价格快照与 charge；终态 charged + refunded = reserved；同 key 重放不新增扣款；终态无悬挂 reserved。示例本轮消费应为 11+11+7=29 点。
- A 消费者余额和账本在 B 全场景前后逐列/行数一致；B 另一组织可发生跨 scope 拒绝所需的 reserve/release 记录，但终态净余额与 reserved 不变。
- `unknown-observed.json` 表示客户端实际收到 1112100002，并记录当时钱包；如要证明数据库中间态 UNKNOWN，须另行在恢复前截取 SQL，不能拿最终 SUCCEEDED 行反推。
