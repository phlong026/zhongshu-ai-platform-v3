# 加盟商管理端功能清单（小程序前端操作级盘点）

> 版本：V1.0 · 2026-11-07
> 来源：zhongshu-ai-platform-v3 仓库 `miniprogram/` 逐文件深挖（基于最新提交 a76f21e「切生产剔除批（六）」之后的代码状态）
> 用途：加盟商员工 Web 管理后台（见同目录《加盟商员工Web管理后台界面设计-20261107.md》）功能承接的业务依据——Web 端与小程序同构不同形，本清单即"同构"的功能全集。
> 颗粒度：操作级——每个功能注明「能做什么操作 / 看什么数据 / 所在页面 / 可见角色」。

## 一、角色 × 入口总览

11 个角色定义于 `utils/organization.js`，后端岗位 roleCode 与之同名（`/platform/posts/mine`）；导航由 `utils/workbench-nav.js` 按当前岗位接管（X-Post-Id 切岗即换整套导航）。

| 角色 | Tab/落地页 | 管理职能域 |
|---|---|---|
| boss 老板 | 工作台(admin/home)·业务·工程·我的 四 Tab | 驾驶舱/审批/组织/目标/提成/复核/门店管理（全权限） |
| owner 门店负责人 | 同 boss 四 Tab | 同 boss，按钮按权限码收敛（sales 域只读） |
| sales 业务员 | 业务·创作·方案·客户·我的 | 客资/客户/交易/内容创作 |
| sales-lead 业务负责人 | 同 sales | +客资处置/转交/团队监督 |
| engineer 工程人员 | 工程首页·项目·材料·我的 | 工程执行 |
| project-manager 工程负责人 | 同 engineer | +计划/结算/归档/换人 |
| finance 财务专员 | 财务工作台(finance-desk)·账本·我的 | 收付登记/对账 |
| finance-lead 财务负责人 | 同 finance | +退款作废/更正链/跨组织补证 |
| hq-design-admin 设计行政 | 委托队列(workflow/commission?view=admin)·项目·我的 | 设计委托全链 |
| hq-operations / lead | 默认五 Tab 过滤 | 零权限码岗，授权后随组启用 |

## 二、门店管理层（boss / owner）

### 2.1 经营驾驶舱（pages/admin/home，owner-home.js）

| 功能 | 内容与操作 |
|---|---|
| 平台待办区 | GET /platform/todos 渲染：标题+类型标签+金额+可办理/等待他人办理；可办理行点击直达办理页 |
| 本月经营六数 | ①设计委托金额(万+目标完成%)②回款金额(万+待核算N笔)③设计委托单数(+报价中N单)④新增线索(+内容获客N条)⑤有效客户⑥到店客户；月 picker 切换历史月；每项点击下钻原单明细 |
| 今日账本 | 今日已收(总额+笔数)/今日要付(到期应付+前2笔明细，点击→项目账)/待你处理(例外审批件数)/昨日已付/月度回款付款汇总；附「付款自动核对」信任文案 |
| 今日待办 | 五分组 chips：全部/例外审批(去审批)/结果复核(去复核)/责任交接(去交接)/绩效任务 |
| 当前业务 | 业务各阶段客户计数；「预约到店」「内容获客」信号卡；三条经营提示（超7天未跟进🔴/今日待跟进🟡/本月发布内容🟢）均可下钻 |
| 当前工程 | 在建/待开工/本月交付/延期 4 计数；在建工地卡（图片/当前节点/进度点/分期收款标签：开工款已收·逾期·待收·封顶款·收款约定待确认） |

### 2.2 经营分析（pages/admin/finance，owner-business.js）

| 功能 | 内容与操作 |
|---|---|
| 经营预警三类 | ①工期延误超3天（直达节点页）②成本超支（预计毛利<0，直达成本）③7日应付现金覆盖缺口（直达应付/资金） |
| 三级经营看板 | 公司经营（账户余额/资金覆盖/待收款含逾期/7日到期应付）；业务经营（六数）；工程经营（材料到货/在建/延期含整改待复验/工程回款率） |
| 收支趋势与构成 | 近6月收支双条形图；收入构成与实际支出构成两列（金额+占比），推广费用入口 |
| 应收账款管理 | 总额+逾期金额；账龄六桶（未到期/1-30/31-60/61-90/90+ /未约定）；明细按逾期优先；**催款话术一键复制**（含称呼/期次/金额/逾期时态）；**查看现场资料**（最新真实施工照片）；**催收记录**（业主承诺付款日/已催收状态，老板只读） |
| 应付账款管理 | 总额+7天内到期；账龄分桶；状态标签（待付款/待复核/需补充） |
| 月度结账 | 确认结账/重新核对 → operating.snapshot 归档（002 幂等提示）；历史月未归档显示空态 |
| 经营绩效聚合 | 4 项目标进度条+5 部门分组人员绩效行 |

### 2.3 目标与绩效（pages/admin/tasks）

| 成员视图 | 负责人只读查看成员绩效进展 |
| 目标设置 | 公司/部门/员工三级目标表单（旧目标页已只读，统一走绩效任务） |

### 2.4 回款提成（pages/admin/commission）

| 步骤 | 操作 | 角色 |
|---|---|---|
| ①确认提成规则 | 选项目→选归属人→填固定总额→上传依据→核对→保存（总额自动对半拆到开工款/封顶款） | boss |
| ②阶段状态跟踪 | 每项目每阶段：应收/净实收/本期提成/已付/未付/状态（待足额到账→可生成应付→待付款→已付清；退款冲正后=待人工核对） | boss/finance |
| ③生成应付 | 阶段净实收足额后生成提成应付 | finance |
| ④登记付款 | 跳财务台应付款；付款前强校验规则版本/金额/归属人/收款事实签名 | finance |
| ⑤人工核对 | 收款事实变化（退款/冲正/更正）后上传依据核对，通过才继续付款 | boss |

### 2.5 组织与人员（pages/account?view=api-members，api/org.js）

| 功能 | 操作 |
|---|---|

### 2.6 审批与门店管理

| 功能 | 操作 | 角色 |
|---|---|---|

| 合同变更确认 | 增项/负责人变更：合同差额/收款计划影响/工期延长/材料联动+业主同意凭据→确认/退回/补充重提 | boss |

| 责任交接 | 标记需交接（原因）/转交（接替人 picker+原因+核对，立即生效历史保留）/交接记录查询 | boss/owner+负责人 |

## 三、财务部（finance / finance-lead）

### 3.1 财务工作台（pages/admin/finance-desk）

| 视图 | 内容 |
|---|---|
| desk 工作台首页 | 平台账簿三指标（本月已登记收款/付款/退款净额）+台账预览+到账待确认+快捷办理入口+待办预览 |
| flows·应收 | 门店=建造合同分期（合同额/有效实收/未收/逾期）；总部=设计款首尾款+材料代垫 |
| flows·应付 | 报销/设计/往来/材料四分类；已登记付款/剩余可登记/历史占用 |
| flows·流水 | 实收/实付/历史退款三分类；月份 scope+类别/状态筛选+到期/金额/最新排序+分页 |
| flows·月末对账 | 毛额已登记收款/退款对客/净实收/异常资金待关联/日期待核→「完成本月对账」 |
| projects 项目账 | phase 筛选；合同/实收/未收/逾期+设计首尾款进度+成本与毛利+分期结算（blockers+重结算）+七个跳转 |

### 3.2 平台账簿登记五类（platform-actions.js，全部幂等键+代次戳防重防串台）

| 付款登记 | 必选关联应付/金额/日期/流水 |

| 应付登记 | 收款方/阶段/总额/项目/约定依据 |

## 四、销售部（sales / sales-lead）

| 功能 | 操作 |

### 4.2 交易流水线（pages/workflow，sales 12 步链）

| 步骤 | 操作 |
|---|---|
| ①需求登记 | 面宽/进深/层数/风格/说明→版本号 V+1，预填最近一版 |
| ②报价测算 | 人工核定面积三项+基础/结构/屋顶单价+六项外装开关→前端编译+服务端计算→分项结果 |
| ③报价单导出 | 冻结快照→canvas 渲染→预览/存相册/发图片/导出 PDF/分享 |
| ④合同签订 | 三期收款计划（Σ=合同总额校验）→同客户仅一份有效主合同 |
| ⑤合同签订/作废 | 列表卡（三期约定/累计分笔/余额）；sign 带 revision；void 填原因 |
| ⑥分笔回款 | 期款行办理回款：金额≤剩余可收/方式/银行流水/到账日期→写通 B1 账簿 |
| ⑦交付验收 | 按序推进 4 节点（方案交付→方案确认→施工交付→施工验收，乱序拦截） |
| ⑧业务进度 | 需求版本/报价历史/合同卡+期款/交付节点聚合 |

### 4.3 内容获客（pages/creation + studio + ai-video + growth）

| 功能 | 操作 |
|---|---|
| 创作三模式 | 爆款二创/数字人口播/AI 视频入口 |

| 发布设置 | 标题/文案/话题/组织账号/封面/定时→发布 |
| 发布回执 | 五态（待登记链接/已发布/待核实/失败/待发布）；链接登记全局唯一 |

| 素材库/我的作品 | 草稿与已保存作品管理 |

## 五、工程部（engineer / project-manager）

### 5.1 项目与计划（pages/build）

| 功能 | 操作 |
|---|---|
| 工程首页 | 在建/待开工/待交付/全部统计+最近项目+平台待办区 |
| 项目列表与新建 | 在线列表+筛选（待接收/待开工/在建/待交付/已交付/已归档）；新建（同名查重） |

| 实际开工 | 日期+现场情况+开工凭据（累计已核算门禁） |
| 施工计划 | 节点清单整体保存（日期齐全+不重叠）/整体改期（材料需用日期随移）/版本快照历史/xlsx 导入/换负责人（CAS，旧负责人立即失权） |

### 5.2 施工与材料

| 功能 | 操作 |
|---|---|
| 节点记录 | 节点完成（日期/情况/凭据/材料免到场勾选→材料门禁）；现场拍照≤9张；节点更正留痕；最近完成撤回（下节点无记录+未收封顶款门禁） |

| 材料采购 | 供应商/单价/运费/凭据→生成财务应付（已付清锁定） |
| 到货质检 | 供应事项显式选定+实到数量/收货流水号唯一/合格·不合格/凭据；实到更正留痕 |

| 催到货 | 承诺日期+说明（同日同内容幂等） |

### 5.3 收款、费用与收尾

| 功能 | 操作 |
|---|---|
| 工程收款 | finance 岗登记（TOPPING 门禁）；工程岗催收回访（承诺付款日） |

## 八、权限模型（Web 端需对齐）

**数据可见性五函数**（utils/authority-v2.js）：
- customer(p)：boss/owner=全公司；sales-lead=本团队；sales=本人+参与者+授权；工程岗=有移交且本人相关
- project(p)：工程=boss/PM(团队或本人)/engineer(执行人)
- rowAccess(r)：财务行 boss/owner/finance 族=全部；业务来源行→sales 本人/lead 团队；工程来源行→工程团队
- supplement(r)：补证资格=岗位匹配原来源+当前经手人
- workflow(view,p,write)：money-review 仅 boss；transfer=boss 或 sales-lead

**关键收敛规则**：
- 作废类权限（退款作废/付款作废）仅 finance-lead/boss
- owner 与 boss 差异=owner sales 域只读（无 write/collect），按钮级权限码收敛
- 薪酬奖金线下办理，系统不提供结算（payroll 命令被显式拒绝）
- 审批零线上（审批=登记例外+线下签字，系统只做登记/通知/计算/提醒）

**领域命令全集**：管理操作约 40 个命令（management-company/assignments、approval-settings、handover-mark、commission-policy/release/reconcile、pay、pay-supplement、incoming-register、direct-register、plan-submit、credit-exception、expense 六命令、funds-confirm、month-reconcile、operating-snapshot、set-roles、performance 系列、transfer、disable/restore、review、appeal-resolve、change 系列、cross 系列）——详见 `pages/admin/model.js` 及 utils 各域模块。
