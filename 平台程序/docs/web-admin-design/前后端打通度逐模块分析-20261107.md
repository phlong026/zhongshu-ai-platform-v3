## 四、运行时阻塞清单（按依赖序）

1. `API_BASE=''`（config/env.js）——前端唯一硬阻塞
2. `PF_SMS_*` 六值——real client 已实现，缺凭据生产启动失败
3. `PF_WX_STAFF_APPID/APPSECRET`——不在守卫登记内，部署 checklist 必查
4. `ZS_WX_APPID/APPSECRET` + `ZS_XPAY_*` + `ZS_RECHARGE_ENABLED=true` + MP 建道具
5. `ZS_COS_*` 五件套
6. AI 五家 key（独立可缺，缺哪家报 1_114_000_006，可分批）
7. 微信 request 合法域名 + appid 核实
