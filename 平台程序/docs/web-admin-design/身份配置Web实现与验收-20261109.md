# 身份配置 Web 实现与验收

本文承接《身份配置Web任务书评审-20261109》，覆盖组织开通入口、员工岗位会话、本组织部门/员工/任职维护与交接。平台全局组织开通仍使用 system 权限，本组织人员管理使用当前 StaffPost 权限，不更换员工和岗位数据模型。

## 本轮新增读取契约

相对路径的部署前缀由请求层统一配置（通常为 `/admin-api`）。所有接口沿用 `{code,data,msg}` 包络和既有登录令牌、tenant-id；业务岗位请求携带 `X-Post-Id`。

### GET /platform/posts/mine

返回本人有效任职数组，每项为：

```json
{
  "postId": 11,
  "userId": 7,
  "orgId": 100,
  "orgName": "示例门店",
  "orgType": "store",
  "roleCode": "sales",
  "teamId": null,
  "lead": false
}
```

本轮增加 orgName，来源为组织根部门名称；列表查询与任职实时校验之间失效的岗位会被移除，不再返回 null 元素。同一响应内相同组织名称只读取一次。无需先选择岗位，不能借此读取他人任职。

### GET /platform/posts/current-context

返回经过 `CurrentPost.require()` 实时校验的当前任职及组织管理工作区能力：

```json
{
  "post": {
    "postId": 11,
    "userId": 7,
    "orgId": 100,
    "orgName": "示例门店",
    "orgType": "store",
    "roleCode": "boss",
    "teamId": null,
    "lead": false
  },
  "permissions": ["platform:org:query", "platform:org:manage"]
}
```

permissions **只包含本次组织管理工作区支持的两个权限码**，每项均经现有 `SystemDirectory.roleHasPermission(当前岗位roleCode, permission)` 判断，与 `@post.has` 同源；不是账号全部角色权限，也不是平台全局权限集合。业务员没有这些权限时返回空数组；平台超管的 system 权限不会因此自动变成业务组织任职。

多岗未选择、岗位被撤销/组织停用、没有有效任职时沿用 RequestCurrentPost 的业务错误，不返回可继续操作的旧上下文。客户端应先清旧上下文，再允许重新选择有效岗位；菜单隐藏不能替代服务端权限拒绝。

### GET /platform/org/post-templates?orgId=当前组织

复用 `platform:org:query` 与当前组织范围校验，返回 `[{roleCode,line,lead}]`。读取 pf_post_template，按当前组织的 orgType 过滤 org_types 并排序；不得请求其他组织或在前端硬编码岗位选项。现有业务域注册十三个模板，三处身份/人员页面共用中文标签。指派时仍由既有服务再次验证模板、组织、部门与账号。

此接口只提供允许指派的角色选项，不给员工自选未授权角色；员工登录岗位列表仍仅来自 posts/mine。Web 能配置某模板，不代表小程序该岗位所有业务页面均已开放。

## 既有写接口复用

组织开通：POST `/platform/org/onboard`，仅 `platform:org:onboard` 平台授权人员使用。

组织内人员：GET/POST `/platform/org/teams`、GET/POST `/platform/org/staff`、POST `/platform/org/posts`、DELETE `/platform/org/posts/{postId}`；orgId 来自已校验的当前任职。手机号已存在则复用账号，同岗幂等与部门冲突沿用后端规则。

组织停职：POST `/platform/org/staff-status` 的 active=false 只撤本组织岗位；恢复使用手机号重新录入/任职指派，不能调用 active=true 恢复已撤任职，不能启用被平台全局停用的账号。

正常交接、紧急撤权、待分配：分别复用 staff-handover、staff-emergency-revoke、handover-pending。结果逐域区分 HANDED_OVER、NONE、PENDING_UNASSIGNED、NOT_INTEGRATED、SCAN_FAILED；紧急撤权已提交后，扫描失败不能展示为撤权失败。
