# 快速预算：复用原 AI 设计后台基准价

本改动不新增价格维护接口或基准价数据表。原 AI 设计后台是单一价格来源；B 保存的个人覆盖价和已生成预算的冻结快照仍按原规则隔离。

## 已定位的原系统

- 同服务器原项目：`/opt/zhongshu`，服务 `zhongshu.service`。
- 原设计 API 地址：`https://api.zszhj.com`；灵感库当前也从这个项目读取。
- 现有发布价格接口：`GET /admin-api/design/v1/budget/prices?regionCode=WUHAN&status=PUBLISHED&pageSize=100&pageNo=1`。
- 权限：原系统只读 `design:budget:query`，所属租户 1。继续使用该接口本身的正常身份与权限检查。

## 数据链路

目录可用性、预算测算、当地单价展示以及个人地区报价基准版本均读取 `AiDesignBaselineSource`。客户端不持有源系统凭据，不直接调用管理接口。

一次测算按相同时间点使用同一源价格集合；新测算重新查询源接口。完整遍历源接口分页，保留原始长 ID、价格版本、生效与失效时间。未来生效、已失效价格不参与当前测算；缺价保持 null，源错误不回落到本地导入价。个人覆盖价优先级保持原规则。

个人地区报价的版本历史可以保存源价格的不可变历史副本，这不是单独维护的基准价格。源后台改价后，新默认预算使用源发布价；历史预算金额保持冻结。

## 部署配置与本轮边界

Provider 默认启用直接取价；配置项见 `deploy/platform/design-provider.properties.example`。已按用户明确授权在原系统创建专用只读服务账号和独立 OAuth 客户端，仅授予 `design:budget:query`，通过原有 OAuth 密码授权和刷新授权接口取令牌。后端自动缓存短期令牌并在过期或 401 时续期，刷新失效后仅重新认证这个服务账号。凭据只保存在服务器秘密配置中，不进入仓库、聊天输出或小程序。

真实验证：已发布价格接口读取成功（35 条），改价探测被 403 拒绝，令牌刷新成功；编译后的新 `AiDesignBaselineSource` 也在服务器上直接读取原 API 成功，未读取本地价格表，未发起收费动作。

连接配置与 systemd LoadCredential 已准备到现有 Provider 的外部配置及独立 drop-in；仅执行 daemon-reload，未重启服务。源码、认证与真实只读验证均已完成，本轮没有发布线上程序或小程序版本，线上生效仍需常规部署。没有修改源基准价或现有用户权限。

备选模式仍支持外部令牌文件；启用直连后，令牌或源接口异常时明确失败，不使用旧导入价。
