# 20-共享文件交付与访问契约（M11-T03 阶段A冻结）

冻结时间：2026-11-04。依据：基-1 资产/文件服务实现（franchise-asset + design asset 票据制）、M5 资产通道权限分派（stage5-m5-done）、11 号需求（阶段0-基1）。本文将既有实现的输入/输出/状态机/错误/权限矩阵固化为契约，供各业务模块（财务凭证、工程凭据、合同附件、内容素材）直接实施——业务只依赖本契约，不依赖 M11-T03/B（真实渠道验收）。

## 一、资产类型与受众

| assetType | 受众 | MIME | 上限 | 审核 | 业务用途 |
|---|---|---|---|---|---|
| FIN_VOUCHER | B_END | pdf/jpeg/png | 20MB | 免审（B_END 跳过审核与 scanner） | 财务收付款凭证 |
| ENG_DRAWING | B_END | pdf/jpeg/png | 30MB | 免审 | 工程图纸 |
| ENG_SITE_PHOTO | B_END | jpeg/png | 10MB | 免审 | 工程现场照片 |
| CONTRACT_ATTACHMENT | B_END | pdf/jpeg/png | 20MB | 免审 | 销售合同附件 |
| CONTENT_ASSET | B_END | 50MB 四 MIME | 50MB | 免审 | 内容素材 |
| C_END 各类 | C_END | 各异 | 各异 | 走审核 | C 端设计链（本契约不涉及） |

**C/B 隔离机制（按 AssetService 实际实现）**：双入口按 `expectedAudience` **双向校验**——createServiceTicket 仅受理 B_END 类型、createTicket（C 端）仅受理 C_END 类型，B_END 资产无法经 C 端入口上传/访问。新增资产类型仍须显式评估受众归属（14 号 §隔离）。

## 二、交付状态机（B_END 免审通道）

```
1. createServiceTicket   POST /franchise/assets/upload-tickets
   入（冻结字段）：{ assetType, mimeType, sizeBytes, sha256 }（sha256 为原始字节申报值）
   出（冻结字段）：{ assetId, uploadUrl }（uploadUrl=生产 COS 签名 URL / dev bytes 端点，按 profile）
   校验：类型策略（MIME/大小/受众 B_END）、操作者岗位通道（见 §四）
   CONTENT_ASSET 四种 MIME（冻结）：image/jpeg、image/png、audio/mpeg、video/mp4
2. 原始字节上传   PUT uploadUrl（生产 COS 签名 URL）/ POST dev bytes（仅 local/zsdev）
   字节哈希必须与申报 sha256 一致——complete 时校验，失配拒绝
3. complete   POST /franchise/assets/{assetId}/complete
   校验：ticket 领取者一致、字节存在、大小/SHA 一致
   状态：PENDING → ACCEPTED（B_END 免审：固化 PASSED/PASSED，scanner 产出列 NULL）
   失败语义：未上传/大小失配/SHA 失配 → **终态 REJECTED（固化，可能以成功 HTTP 响应返回——客户端必须检查 uploadStatus 字段而非仅 HTTP 状态）**；重复 complete=CAS 拦截（一方 ACCEPTED，另一方按既有行重读映射）。
   恢复指引（冻结）：complete 失败（REJECTED）后**原 assetId 已不可用**——必须重新签票取得新 assetId 重走状态机，禁止对原资产持续重试 complete。
4. 业务引用   各域写端点携带 assetId（如 FinReceipt.voucherFileId）
   校验：validateReference——资产存在 + ACCEPTED + 本组织属主（fr_fin_file 双轨兼容期内旧通道并行）
5. 下载   POST /franchise/assets/{assetId}/download-tickets → 签名 URL（时效受限）
   字节原样出库，sha256 与申报一致（可复核）
```

## 三、错误与失败处理（业务端展示约定）

| 场景 | 码/语义 | 业务端处理 |
|---|---|---|
| 类型/受众不符 | 1_071_000_001 族 | 提示类型不支持，不得降级本地 |
| 通道权限不足 | 分派拒绝（M5 requireChannelPermission） | 提示无该类文件权限 |
| 字节哈希失配 | complete 拒绝 | 提示重新上传，不得引用 |
| 未上传即 complete | 拒绝 | 提示先完成上传 |
| 重复 complete | CAS/幂等 | 以既有状态为准 |
| 签名过期 | 下载 403 | 提示重新获取下载票据 |
| 生产不依赖 /platform/dev/** | 部署守卫 | dev bytes 缺失即上传失败，不得伪造成功 |

## 四、通道权限矩阵（M5 requireChannelPermission，严格对齐 8xx 种子）

| assetType 类别 | 授权岗位线 |
|---|---|
| FIN_VOUCHER | fin 线（finance/finance-lead） |
| ENG_* | 工程线（engineer/project-manager） |
| CONTRACT | sale 线（sales/sales-lead/boss） |
| CONTENT | sales 线（sales/sales-lead） |
| boss/owner | 全类别上传/complete/下载均可（AssetAccessService 上传、complete、下载共用同一角色矩阵——现状如实记录） |

兼岗按**请求当前岗位**（X-Post-Id）判定，不按账号全部角色；上传票据签发与下载同矩阵。「严格对齐 8xx 种子」仅约束 query 类岗位集合，不表述为写权限收紧。未知类型放行走 1_071_000_001（先于资产校验）。
