## 建议实际测试顺序

1. 总部输入品牌、省、市、片区、老板姓名与手机号。核对正式账号与简称，开通并“一键复制”；初始密码只交付一次。
2. 老板用账号密码在开发版登录，按提示修改初始密码，设置默认账号；退出后用全账号、地区简称、姓名拼音与首字母验证匹配。多候选时明确选择门店，不自动选第一家。
3. 老板进入“成员与权限”，为员工开通独立账号，选择岗位并复制凭据。员工单独登录，确认自己的组织和岗位，不能代老板行使管理员权限。
4. 各自先完成账号密码登录，再在登录引导中显式绑定本人微信。退出后使用微信一键登录，核对同一人员、同一门店、同一岗位及已创建的数据；再切回账号密码登录复核。不能因两种登录方式产生两个用户。
5. 同片区开第二家门店，检查新账号追加老板姓名，第一家账号不变；确认多候选选择和本机默认账号生效。

手机号用于管理员核对人员与任职，不再提供小程序短信登录入口。同一自然人在多个组织任职时保留同一用户与密码；不同员工有各自账号和数据权限。存量未配置别名/密码且未绑定微信的账号，须总部按既有流程核对处理；本次不自动重置旧密码或合并用户。
