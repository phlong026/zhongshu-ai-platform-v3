## 复刻方式

按原图宽度换算为 750rpx，校对原图卡片顺序、图片裁切、配色、图标与文案。照片、品牌和图标由提取脚本从用户提供的图稿按独立素材提取，素材清单记录来源区域。工作台品牌标题使用 Noto Serif SC 字体子集；工程内页使用 Noto Sans SC 的常规、中等、加粗三个子集字库，含导航组件。字库随代码内置。工程源图只有位图，具体原始字体尚不能确认，不能据此宣称字体完全相同。

状态栏时间、刘海、微信右上角胶囊和 Home Indicator 由设备与微信绘制。真实设备的状态栏高度、安全区、字体抗锯齿会与效果图不同。原生布局保留这些系统区域，页面可滚动；没有伪造系统栏。

## 内容创作入口与流程

首页“视频创作”或业务页“爆款二创”进入创作中心；“数字人口播”和“AI视频”可直接进入对应界面。创作中心的素材库、任务中心、我的作品和发布记录均有可操作入口。

创作中心使用当前岗位的底部导航；业务岗位高亮“创作”，可直接进入首页、设计、客户和我的。编辑弹层打开时隐藏导航，其余创作和发布内页继续使用返回导航。

本地体验路径：粘贴链接后明确选择“使用示例”，或手动输入文案 → 文案二创 → 数字人口播 → 确认体验演示任务 → 查看进度并选择演示完成 → 视频结果 → 保存作品 → 发布设置 → 确认提交演示发布 → 发布记录 → 查看进度/演示回执。AI视频通过填写描述、选择素材和参数进入同一任务、作品与发布流程。

演示生成和演示发布均需在页面明确确认；不会调用真实AI、扣费或向抖音、视频号提交。图稿中的播放器展示示例海报，未配置真实视频；声音试听也会说明未接入。保存作品指保存本地作品记录。

检查重复保存、重复发布、待核实记录、保存失败和账号失效等分支。完整分析见 `qa/content-creation-flow.md`，视觉证据见 `design-qa.md`。

当前已下发、尚未签认的成果可沿原委托提出修改意见。旧版下发和收图记录留存，新版重新审核、下发、收图及签认；不重复生成原首尾款。建造报价绑定已确认设计版本，改版后旧报价不能用于签约。施工图可按设计委托在签建造合同前补传、审核；工程移交仍检查已签合同、图纸及确认资料。

报价表可从客户的预算结果、正式报价页，以及已保存到客户的快速预算结果进入“导出报价图片 / PDF”。表格按客户提供的样式绘制，包含客户信息、宅基地与建筑尺寸、选型、主体与装饰工程、保险费、管理费及总价，金额统一加粗。PNG为2382×3369像素，PDF为同一表格的单页A4文档；图片提供保存相册和发送文件，PDF可打开后保存或发送。

导出绑定原客户、项目和报价版本。补充信息仅保存在本人的本版表格草稿中，不改写计价面积、配置或金额。已合并计价的门窗、屋面等保留汇总口径，保险从装饰小计移至保险行且只计一次；未单列管理费时不擅自追加模板中的3%。正式报价必须获得本版老板审批，设计更新后旧版不能导出。模拟计价保留模拟标识。
